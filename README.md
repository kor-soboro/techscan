## 읽는 법

[`weekly-reports/`](./weekly-reports/) 폴더에서 최신 날짜 파일을 열어보면 됩니다. 각 리포트는 다음 분류 체계를 따릅니다.

| 분류 | 의미 |
|---|---|
| 👀 **지금 살펴볼 가치** | 즉시 적용·평가할 만한 도구·기법 (메인 큐레이션) |
| 📝 **인지만 해두면 OK** | 트렌드 인식 차원 (대기업 동향, 새 모델 등) |
| 🗑 **스킵해도 됨** | 산업 뉴스 · 이론 논문 — 한 줄로만 |
| ⚠️ **ToS 제약 가능 카테고리** | 일부 플랫폼의 third-party OAuth 정책에 따라 사용 제약이 있을 수 있는 도구. 도입 전 본인 상황·계약·정책 확인 필요 |

각 메인 항목에는 다음 정보가 포함됩니다.

- **무엇** + **쉬운 비유** (일상 비유로 핵심 컨셉 풀이)
- **인증 방식 · 비용 · 주목할 가치** 라벨 표
- **유사 카테고리 비교** (해당 카테고리에 알려진 도구가 있을 때)
- **5분 검증 액션** — 빠르게 핵심을 파악할 수 있는 구체적 행동
- **출처** 링크들

## 큐레이션 기준

- 7일 이내 신선한 항목만 수집 (8일 이상 묵은 것은 제외)
- 객관 서술 — 특정 인물·시스템과 연결한 주관적 평가는 배제
- 인증·비용은 객관 사실. "사용 가능/불가" 단정 대신 사실만 명시
- 가치 있는 항목이 1개뿐이면 1개만 — 채우기용 항목 없음
