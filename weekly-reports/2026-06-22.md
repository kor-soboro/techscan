### 1. [Agentjacking — Sentry 오류 위조로 AI 코딩 에이전트 탈취](https://tenetsecurity.ai/blog/agentjacking-coding-agents-with-fake-sentry-errors/)

**무엇**
Tenet Security가 6월 17일 공개한 공격 기법. 프로젝트 소스코드에 공개된 Sentry DSN(오류 수집 식별자)을 이용해 가짜 버그 리포트를 Sentry에 주입하면, AI 코딩 에이전트가 Sentry MCP 서버를 통해 해당 리포트를 읽고 공격자의 명령을 개발자 머신에서 그대로 실행한다. Claude Code · Cursor · OpenAI Codex에서 Windows · macOS · 클라우드 파이프라인 전반에 걸쳐 검증됐으며, 탈취 대상은 환경변수, AWS 자격증명, npm 토큰, Docker 자격증명, Git 자격증명, 프라이빗 레포 URL 등이다.

**쉬운 비유**
회사 건의함에 악의적인 쪽지를 몰래 넣어두면, 비서가 그 쪽지를 진짜 건의사항으로 믿고 중요한 서류를 외부로 보내는 것과 같다. 비서는 건의함 내용을 신뢰하기 때문에 이상함을 알아채지 못한다.

| 라벨 | 값 |
|---|---|
| 공격 벡터 | Sentry 공개 DSN을 통한 외부 이벤트 주입 → Sentry MCP 서버 → 에이전트 명령 실행 |
| 영향 범위 | 환경변수, AWS 자격증명, npm/Docker/Git 토큰, 프라이빗 레포 URL |
| 실제 노출 현황 | 2,388개 조직 노출 확인, 100개 이상 글로벌 기업 검증(포춘 100 포함), 2026-06-17 발표 |
| EDR·WAF 우회 | 우회(모든 행동이 기술적으로 권한 내 정상 동작으로 처리됨) |

**유사 공격 패턴 비교**

| | Agentjacking | 일반 프롬프트 인젝션 | 악성 MCP 서버 설치 |
|---|---|---|---|
| 주입 경로 | Sentry 오류 이벤트 → MCP 서버 | 웹페이지·문서 등 외부 콘텐츠 | 에이전트가 외부 MCP 서버 직접 연결 |
| 보안 도구 우회 | 우회 가능 | 부분 우회 | 우회 가능 |
| 탐지 난이도 | 높음(합법 흐름과 구별 어려움) | 보통 | 낮음(서버 출처 확인 가능) |

**5분 검증 액션**
Sentry MCP 서버를 에이전트에 연결해 사용 중이라면: ① Sentry 대시보드 → Settings → Client Keys에서 공개된 DSN 목록 확인, ② 에이전트에 전달되는 Sentry 이슈 내용에 마크다운 형식 명령어가 포함되는지 수동 검토, ③ [Tenet 원문 PoC 설명](https://tenetsecurity.ai/blog/agentjacking-coding-agents-with-fake-sentry-errors/)을 읽고 에이전트가 외부 입력을 어떤 지점에서 신뢰하는지 파악.

### 2. [Claude 플랫폼 WIF(Workload Identity Federation) 정식 출시](https://claude.com/blog/workload-identity-federation)

**무엇**
6월 18일 Anthropic이 Claude 플랫폼에서 WIF를 GA 출시. AWS IAM 역할, GCP 서비스 계정, Azure 관리 ID, GitHub Actions 토큰, Okta 등 OIDC 호환 프로바이더로 발급된 단기 토큰만으로 Claude API를 인증할 수 있다. 기존 sk-ant-... API 키를 생성·교체·유출 관리하지 않아도 되며, 워크로드별로 서비스 계정을 만들어 독립적인 감사 추적이 가능하다. Claude Code도 WIF 인증을 지원한다.

**쉬운 비유**
사원증(기존 API 키) 없이 회사 출입 카드 시스템(이미 쓰는 사내 인증)으로 특정 시스템에 접근 권한을 받는 것과 같다. 별도 열쇠를 만들거나 잃어버릴 걱정이 없다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | OIDC 토큰 (AWS IAM / GCP 서비스 계정 / Azure 관리 ID / GitHub Actions / Okta 등) |
| 비용 | 인증 기능 자체는 추가 비용 없음; API 사용 요금은 기존과 동일 |
| 주목할 가치 | CI/CD 파이프라인·자동화 에이전트 배포에서 정적 API 키를 제거하는 공식 경로가 생겼다. Admin API로 서비스 계정을 프로그래밍 방식으로 관리할 수 있어 대규모 에이전트 배포에서 자격증명 거버넌스를 개선할 수 있다. |

**유사 인증 방식 비교**

| | Claude WIF | 기존 sk-ant-... 키 |
|---|---|---|
| 키 교체 부담 | 없음 (단기 토큰 자동 갱신) | 정기 수동 교체 필요 |
| 유출 위험 | 낮음 (짧은 만료 시간) | 높음 (장기 노출 가능) |
| 워크로드별 격리 | 서비스 계정으로 독립 감사 추적 | 키 공유 또는 다중 키 수동 관리 |
| 지원 도구 | Claude API·SDK·Claude Code | Claude API·SDK·Claude Code |

**5분 검증 액션**
[공식 WIF 문서](https://platform.claude.com/docs/en/manage-claude/workload-identity-federation)에서 사용 중인 IDP(AWS·GCP·GitHub 등)에 해당하는 설정 예시를 확인. GitHub Actions 사용자라면 워크플로 YAML에 `anthropic-ai/auth` 액션을 추가하는 10줄 예시로 즉시 테스트 가능.

- **[MiniMax M3 오픈웨이트 가중치 공개](https://the-decoder.com/minimax-m3-open-weight-model-with-a-million-token-context-challenges-proprietary-leaders/)** — 6/1 출시, 6/11 전후 Hugging Face 가중치 공개. 1M 토큰 컨텍스트 + 프론티어급 코딩(SWE-Bench Pro 59.0%, Terminal-Bench 2.1 66.0%) + 네이티브 멀티모달 컴퓨터 유즈를 동시에 지원하는 현재 유일한 오픈웨이트 모델이라고 MiniMax가 주장한다.
