# Weekly AI Agent Tech Scan — 2026-07-20

## 🎯 TL;DR

- Grok Build(xAI)가 7/15 Apache 2.0으로 오픈소스화되어 ~84만 줄 Rust 코드로 컨텍스트 조립·툴 실행·스킬/플러그인/훅/MCP 통합 구조를 공개했다. 저장소 전체 GCS 업로드 논란이 발단이었던 만큼 코드 내 해당 로직의 실제 형태를 직접 확인할 수 있다.
- Moonshot AI의 Kimi K3(7/16)가 에이전트 코딩 벤치마크에서 Claude Opus 4.8을 상회하며 병렬 에이전트 처리 특화 버전(K3 Swarm Max)까지 공개됐다.
- Thinking Machines(Mira Murati)의 Inkling(7/15)이 975B MoE 오픈 웨이트 멀티모달 모델로 Hugging Face에 공개됐다.
- 지난주 다룬 MCP 2026-07-28 최종 스펙 확정까지 8일 남았다. Beta SDK(Python v2, TypeScript v2, Go v1.7.0-pre.1, C# v2.0.0-preview.1)가 출시된 상태이며 `initialize` 핸드셰이크 제거 등 breaking change 대응 마감이 임박했다.

## 👀 지금 살펴볼 가치

### 1. [Grok Build](https://github.com/xai-org/grok-build) — 프로덕션 에이전트 CLI 전체 코드 공개 (Apache 2.0)

**무엇** xAI의 코딩 에이전트 CLI 전체 소스코드(Rust, ~844,530 라인)가 7/15 Apache 2.0으로 공개됐다. 오케스트레이터, 툴 실행기, 전체 TUI, 그리고 스킬/플러그인/훅/MCP 서버 연동 레이어의 네 서브시스템이 포함된다. 기여는 현재 read-only로 제한, 기반 모델(grok-build-0.1)은 독점 API를 통해서만 호출된다.

**쉬운 비유** 고급 요리사가 레시피 북을 공개했지만, 핵심 재료는 자기 식당에서만 살 수 있는 형태. 레시피를 읽고 조리 순서를 배울 수 있지만, 그 재료 없이 완전히 똑같은 요리를 집에서 만들 수는 없다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | xAI API key (BYOK 형태, 또는 xAI 구독) |
| 비용 | 오픈소스(Apache 2.0); 모델 API 호출 비용은 xAI 요금제 별도 |
| 주목할 가치 | 실제 프로덕션에서 운영 중인 에이전트 CLI의 컨텍스트 조립·툴 파싱·MCP 통합 방식을 라인 단위로 확인 가능. 유사 에이전트에서 이식된 툴 구현체가 포함되어 크로스-레퍼런스 학습 소재로도 유용 |

> **주의**: 공개 계기가 저장소 전체를 외부 GCS 버킷으로 전송하는 버그(v0.2.93) 발견이었다. xAI는 7/12 기본값을 비활성화했고 기존 수집 데이터를 삭제 중이라 밝혔으나, 코드 내 해당 업로드 로직이 여전히 존재한다는 보고가 있다. 프로덕션 환경에 배포 전 코드 검토 권장.

**유사 카테고리 비교**

| | Grok Build | Claude Code | Aider |
|---|---|---|---|
| 라이선스 | Apache 2.0 (클라이언트) | 독점 | Apache 2.0 |
| 백엔드 모델 | grok-build-0.1 (독점 API) | Claude 시리즈 (BYOK) | 모든 LLM |
| 클라이언트 구현 언어 | Rust | — | Python |
| 스킬/플러그인/훅 | ✅ | ✅ | 제한적 |
| MCP 통합 | ✅ | ✅ | ❌ |
| 외부 기여 | read-only | 없음 | ✅ |

**5분 검증 액션** `xai-org/grok-build` README에서 ARCHITECTURE 섹션 확인 → `src/orchestrator/` 디렉터리 구조 훑기 → 스킬·훅 정의 방식이 익숙한 다른 에이전트와 어떻게 다른지 비교

- **[Kimi K3 (Moonshot AI)](https://kimi.ai)** — 7/16 출시. 2.8T 파라미터 MoE, 1M 토큰 컨텍스트, 에이전트 코딩 벤치마크에서 Claude Opus 4.8 상회 보고. K3 Swarm Max 변종은 대규모 병렬 서브에이전트 조율에 특화. 에이전트 백엔드 모델 선택지가 넓어졌다는 점에서 인지 가치 있음. 단, 여전히 Fable 5/GPT-5.6 Sol에는 못 미침.

- **[Inkling (Thinking Machines Lab)](https://thinkingmachines.ai/news/introducing-inkling/)** — 7/15 출시. Mira Murati 창업 스타트업의 첫 자체 모델. 975B MoE(41B 활성), 45T 토큰 학습, 텍스트·이미지·오디오·비디오 네이티브 처리. 오픈 웨이트(Hugging Face 제공), 사내 파인튜닝 플랫폼 Tinker와 결합. "최강 모델이 아닌 커스터마이징 출발점"이라는 명시적 포지셔닝이 특이점. 에이전트 전용 모델을 직접 파인튜닝하려는 팀에 참고 가치.

- **[MCP 2026-07-28 최종 스펙 D-8](https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/)** — (지난주 리포트에서 RC 소개) Beta SDK 4종(Python v2, TypeScript v2, Go v1.7.0-pre.1, C# v2.0.0-preview.1)이 6/29 출시됐으며 7/28 최종 스펙 발행 전 검증 마감이 임박했다. 기존 MCP 서버에서 `initialize` 핸드셰이크 의존, Roots/Sampling/Logging 사용, `-32002` 오류코드 처리 코드가 있다면 이번 주 안에 점검 필요.
