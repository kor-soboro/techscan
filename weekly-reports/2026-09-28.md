- **Claude Opus 5.5**와 **GPT-6 Sol**이 같은 날 출시되며 에이전트 실무자에게 선택지가 생겼다. Opus 5.5는 장시간 코딩 에이전트에 특화, Sol은 GPT-5.6 대비 API 비용 50% 절감이 포인트.

### 1. [GitHub HydraFusion](https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/)

**무엇** GitHub Copilot CLI에 통합된 런타임 멀티모델 오케스트레이션 리서치 프리뷰. 하나의 코딩 작업을 실행 플랜으로 쪼개 여러 공급사 모델을 조합해 처리한다.

**쉬운 비유** 짐 배달 업체가 거리별로 오토바이·트럭·자전거를 배차하듯, 작업 난이도에 맞는 모델을 그때그때 골라 쓰는 물류 허브라고 보면 된다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | GitHub Copilot 구독 (모든 플랜) — Copilot CLI 실험 모드에서 활성화 |
| 비용 | 기존 GitHub Copilot 구독 요금 범위 내 |
| 주목할 가치 | 세 가지 워크플로 패턴(단일 모델 / 캐스케이드 / 비평 후 재작성)을 런타임에 자동 선택. TerminalBench 2.1 기준 Claude Opus 5 단독 대비 비용 67% 절감, 정확도 4.9%p 향상이 측정됨 |

**유사 카테고리 비교**

| | HydraFusion | LangGraph 멀티에이전트 | CrewAI |
|---|---|---|---|
| 오케스트레이션 단위 | 코딩 작업(파일 단위) | 사용자 정의 그래프 노드 | 역할 기반 에이전트 |
| 모델 공급사 혼합 | 자동(런타임 결정) | 수동 구성 | 수동 구성 |
| 셋업 복잡도 | 낮음(Copilot CLI 실험 모드 토글) | 중간 | 낮음~중간 |
| 적용 범위 | Copilot CLI 전용(현재) | 범용 | 범용 |

**5분 검증 액션** GitHub Copilot CLI를 이미 사용 중이라면 `copilot config` → experimental → HydraFusion 활성화 후 동일 작업을 단일 모델과 비교해 토큰 사용량 확인.

### 2. [Claude Opus 5.5](https://www.anthropic.com/claude-opus-5-5)

**무엇** 장시간 에이전트 코딩·지식 작업에 특화된 Anthropic 신규 모델. 기본 1M 토큰 컨텍스트, 128k 최대 출력, Adaptive Thinking 항상 활성.

**쉬운 비유** 같은 심부름을 기존 심부름꾼보다 발걸음 수를 줄여서 완수하는 셈이다. 빠르게 끝내되 결과 품질은 그대로 유지한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Anthropic API key (BYOK) |
| 비용 | BYOK 토큰 비용 (공개 가격표: [Anthropic 공식 페이지](https://www.anthropic.com/pricing) 확인) |
| 주목할 가치 | FrontierCode 기준 GPT-6 Astra 대비 약 20% 비용으로 동급 성능. 동일 작업에 도구 호출 수·재시도 횟수가 줄어 에이전트 운영 비용에 직접 영향. Fast Mode 시 Opus 5 대비 최대 2.5× 속도 |

| | Claude Opus 5.5 | GPT-6 Sol | GPT-6 Astra |
|---|---|---|---|
| 포지션 | 장기 에이전트 코딩 특화 | 일반 전문 작업 + 코딩 | 최고 성능 플래그십 |
| API 입력 가격(공개) | 미공개(Anthropic 페이지 확인) | $2/M 토큰 | 미공개 |
| 컨텍스트 윈도우 | 1M 토큰 | 미확인 | 미확인 |
| 에이전트 최적화 | 명시적으로 최적화됨 | 보통 | 보통 |

**5분 검증 액션** Anthropic 공식 페이지 [모델 개요](https://www.anthropic.com/claude/opus)에서 Opus 5 대비 FrontierCode 벤치마크 수치 비교. API 사용자라면 동일 에이전트 루프를 같은 작업으로 실행해 step 수 차이 확인.

### 3. [Google Gemini Antigravity Preview 09-2026](https://ai.google.dev/gemini-api/docs/models/antigravity-preview-09-2026)

**무엇** Gemini API 관리형 에이전트 하네스의 9월 업데이트. 새 하네스(antigravity-preview-09-2026)는 프롬프트 캐싱 개선, 네이티브 코드 검색 도구, 효율적인 줄 범위 파일 편집을 포함한다. Files API와 Credentials API가 새로 추가됐다.

**쉬운 비유** 회사 공용 창고(에이전트 실행 환경)에 들어오고 나가는 파일 관리 데스크(Files API)와 직원 출입 카드 관리 시스템(Credentials API)이 새로 생긴 것과 같다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Google API key (BYOK) — Gemini API 통해 접근 |
| 비용 | Gemini API 토큰 비용 (기반 모델: Gemini 3.8 Flash, 설정 변경 가능) |
| 주목할 가치 | 파일 변경 시 출력 토큰 40% 절감, 멀티턴 소프트웨어 엔지니어링 작업 완료율 최대 6% 향상. **기존 antigravity-preview-05-2026 사용자는 10월 5일 이후 자동 리다이렉트 예정** — 지금 마이그레이션 필요 |

**5분 검증 액션** [AI Studio 관리형 에이전트 페이지](https://aistudio.google.com/learn/managed-agents-updated-harness-files-credentials)에서 신규 하네스 마이그레이션 가이드 확인. 기존 antigravity-preview-05-2026 사용 중이면 deprecation 날짜(10/5) 전 교체.

### 4. [MCP 2026-07-28 사양 — 스테이트리스 전환](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

**무엇** Model Context Protocol의 핵심 아키텍처가 스테이트풀 양방향 세션에서 스테이트리스 요청/응답 구조로 바뀐 공식 사양. 이미 7월에 발표됐지만 Cloudflare Workers 공식 지원이 이번 주 확정됐고, 서버 마이그레이션 현황이 화제가 되고 있다.

**쉬운 비유** 식당 서버(MCP 서버)가 손님 테이블마다 전담 웨이터를 배치하던 방식에서, 어떤 웨이터든 주문서만 보면 처리할 수 있는 방식으로 바뀐 것이다. 테이블 번호 대신 주문서 자체에 맥락이 담긴다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 프로토콜 사양(오픈) — 인증 방식은 구현체에 따라 다름 |
| 비용 | 무료(오픈 사양) |
| 주목할 가치 | initialize/initialized 핸드셰이크와 Mcp-Session-Id 제거. 요청마다 Mcp-Protocol-Version, Mcp-Method, Mcp-Name 헤더로 자기 기술. MCP 서버를 Cloudflare Worker 단독으로 운영 가능 → 스테이트풀 인프라 불필요 |

**유사 카테고리 비교**

| | MCP 2026-07-28 | MCP 2024-11-05 (구버전) |
|---|---|---|
| 세션 관리 | 스테이트리스, 세션 없음 | 스테이트풀, Mcp-Session-Id |
| 서버 호스팅 | Cloudflare Worker 가능 | 영속 프로세스 필요 |
| 라우팅 | HTTP 헤더 기반 게이트웨이 라우팅 가능 | 세션 기반 라우팅 |

**5분 검증 액션** [마이그레이션 가이드](https://wavect.io/blog/mcp-stateless-server-migration-2026/)에서 기존 서버 코드의 initialize 핸들러 교체 범위 확인. Cloudflare 기반 서버라면 [공식 변경 노트](https://developers.cloudflare.com/changelog/post/2026-07-28-cloudflare-mcp-servers-mcp-2026-07-28/) 확인.

## ⚠️ ToS 제약 가능 카테고리

해당 카테고리는 일부 플랫폼의 third-party OAuth 정책에 따라 사용에 제약이 있을 수 있어 별도로 분류합니다. 도구 사용 전 자신의 상황·계약·정책에 맞는지 확인 필요.

- **Third-party OAuth 브리지 도구 (예: pi.dev agent/OAuth 브리지)** — Google Antigravity API를 Google 계정 구독 토큰으로 우회 접근하는 방식. Google AI Developers Forum에 계정 정지 사례([해당 글](https://discuss.ai.google.dev/t/appeal-for-account-disabling-unexpected-tos-violation-via-3rd-party-pi-dev-agent-oauth-bridge/142192))가 보고됨. Antigravity API는 공식 Gemini API key(BYOK) 방식이 원칙이며, 구독 OAuth 토큰 재사용은 ToS 위반으로 분류될 수 있음

- **Anthropic Claude 구독 기반 third-party CLI** — 2026년 초 Anthropic이 Claude.ai 구독 OAuth 토큰의 third-party CLI 재사용에 대한 허용 범위를 좁혔음. 일부 기존 오픈소스 도구가 이 방식을 사용할 수 있으므로, 공식 Anthropic API key 방식으로 전환됐는지 확인 권장
