### 1. [Prime Agent](https://github.com/PrimeIntellect-ai/prime-agent)

**무엇** Prime Intellect가 MIT 라이선스로 공개한 자기개선 에이전트 하네스. 도구·서브에이전트·메모리를 별도 스키마 없이 Python 코드로 운용하는 영속 IPython 커널이 핵심 구조이며, `/refine` 명령으로 에이전트가 자신의 이전 실행 이력을 검토하고 재사용 가능한 스킬로 직접 저장한다. 백그라운드 데몬 모드·예약 실행·서브에이전트 간 통신도 지원한다.

**쉬운 비유** 새 직원이 매번 처음부터 일을 배우는 대신, 스스로 업무 노트를 작성해 다음 번에 꺼내 보는 것 — 그 노트 정리 자체도 직원이 알아서 한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | BYOK — 오픈소스 하네스, 사용자가 원하는 LLM 제공자(OpenAI, Anthropic, 로컬 등)의 API 키 지정 |
| 비용 | 무료 (MIT 오픈소스, LLM 호출 비용 별도) |
| 주목할 가치 | 특정 모델 벤더에 종속되지 않는 구조에서 자기개선 루프를 제공하는 드문 사례. Claude Code·Codex 등 벤더 종속 하네스와 달리 모델을 교체해도 하네스 구조가 유지되며, 에이전트가 생성한 스킬이 다음 세션에 영속됨 |

**유사 카테고리 비교** (에이전트 하네스/코딩 에이전트)

| | Prime Agent | Claude Code | OpenCode |
|---|---|---|---|
| 라이선스 | MIT | 독점 | MIT |
| 모델 종속성 | 없음 (BYOK) | Anthropic | 없음 (BYOK) |
| 자기개선 메커니즘 | `/refine` (이력→스킬 자동 저장) | 없음 | 없음 |
| 실행 환경 | 영속 IPython 커널 | 터미널 | 터미널 |
| GitHub 스타 | 16.6k | — | 194k+ |

**5분 검증 액션** GitHub 리포 README에서 'Architecture' 섹션과 `/refine` 명령 설명을 읽고, `curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh` 로 로컬 설치 후 `prime-agent --help` 출력 확인

### 2. [MCP 2026-07-28 사양](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

**무엇** Model Context Protocol의 주요 사양 업데이트. 가장 큰 변화는 프로토콜이 '연결 유지(스테이트풀)' 방식에서 '요청·응답(스테이트리스)' 방식으로 전환된 것이다. `initialize`/`initialized` 핸드셰이크와 세션 ID가 제거되고, 각 요청이 프로토콜 버전·클라이언트 정보·기능을 직접 포함한다. 신규 추가: Multi Round-Trip Requests(MRTR), 헤더 기반 라우팅(`Mcp-Method`·`Mcp-Name`), 응답 캐싱(`ttlMs`·`cacheScope`), 인증 강화(CIMD + RFC 9207 issuer 검증). Tier 1 SDK 4종(TypeScript, Python, Go, C#) 모두 업데이트됨.

**쉬운 비유** 예약 손님만 받던 식당이 이제 번호표를 뽑고 아무 창구나 가도 되는 방식으로 바뀐 것. 어느 직원이 응대해도 주문서에 모든 정보가 적혀 있기 때문에 가능한 구조다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | OAuth/OIDC 정렬 (기존 Dynamic Client Registration → Client ID Metadata Document 방식으로 변경) |
| 비용 | 오픈 표준 (무료) |
| 주목할 가치 | 서버리스·엣지 플랫폼(Lambda, Cloudflare Workers 등)에 MCP 서버를 배포하기 위해 세션 관리를 직접 구현할 필요가 없어짐. 게이트웨이·로드밸런서가 JSON 본문 파싱 없이 HTTP 헤더만으로 라우팅 가능. 기존 스테이트풀 MCP 서버는 마이그레이션 필요 |

**5분 검증 액션** [blog.modelcontextprotocol.io/posts/2026-07-28](https://blog.modelcontextprotocol.io/posts/2026-07-28/) 에서 'Breaking Changes' 및 'Migration Guide' 섹션 읽기; 운영 중인 MCP 서버가 있다면 세션 핸드셰이크 코드 의존 여부 먼저 점검

**출처** [MCP 공식 블로그](https://blog.modelcontextprotocol.io/posts/2026-07-28/) · [Digital Applied 분석](https://www.digitalapplied.com/blog/mcp-2026-07-28-stateless-spec-agent-infrastructure-2026) · [InfoQ — '스테이트리스 MCP, 결국 API와 같아진 건가?'](https://www.infoq.com/news/2026/08/mcp-stateless-gateway/) · [Equixly 보안 관점 분석](https://equixly.com/blog/2026/08/05/stateless-mcp/)

### 3. [LLM 0.32](https://simonwillison.net/2026/Aug/4/new-release-of-llm/)

**무엇** Simon Willison이 관리하는 멀티프로바이더 CLI 도구 겸 Python 라이브러리. 수백 개 LLM에 단일 인터페이스로 접근. 0.32에서 추가된 주요 기능: 추론 트레이스 스트리밍(stderr 출력), OpenAI Responses API 지원(추론과 도구 호출 혼합 연쇄 가능), 서버 사이드 도구(`WebSearch`, `CodeInterpreter`) 호출, 콘텐츠 주소 기반 SQLite 로그 저장소 도입. GPT-5.6 Luna가 기본 모델로 변경됨.

**쉬운 비유** TV 리모컨 하나로 여러 브랜드 TV를 모두 조종하는 것 — 이번 업데이트로 TV가 '생각하는 과정'을 화면 옆에 별도로 보여주게 된 것.

| 라벨 | 값 |
|---|---|
| 인증 방식 | BYOK — 각 LLM 제공자의 API 키 (OpenAI, Anthropic, Google 등) |
| 비용 | 무료 (Apache-2.0 오픈소스, LLM 호출 비용 별도) |
| 주목할 가치 | 단일 CLI/라이브러리로 추론 트레이스·서버 사이드 도구를 표준화된 방식으로 다룰 수 있어 멀티프로바이더 에이전트 파이프라인 실험·구성 시 유용. `llm-gemini 0.33`(8/13)도 같은 주에 업데이트되어 Gemini 3.7 Flash 즉시 지원 |

**5분 검증 액션** `pip install -U llm` 후 `llm --version` 확인; `llm 'Explain yourself' --reasoning` 으로 추론 트레이스 출력 확인 (OpenAI 추론 모델 기준)

### 4. [book-to-skill](https://github.com/virgiliojr94/book-to-skill)

**무엇** 기술 서적 PDF(EPUB, DOCX, HTML, MOBI 등 다수 포맷 지원)를 에이전트 스킬 파일로 변환하는 CLI 도구. 챕터 단위 청킹으로 핵심 개념 파일·챕터별 레이지로드 파일·용어집·패턴 참조·체크리스트를 자동 생성한다. 생성된 스킬은 Claude Code, GitHub Copilot CLI, Amp 등 Agent Skills 표준을 따르는 환경에서 동작한다. 파일 처리는 전부 로컬에서 이루어지며 클라우드 업로드는 없다.

**쉬운 비유** 두꺼운 요리책을 통째로 들고 다니는 대신, 레시피를 색인 카드에 정리해두고 필요할 때만 꺼내 보는 것 — 카드 정리도 자동으로 된다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 해당 없음 (로컬 파일 처리, 클라우드 의존 없음) |
| 비용 | 무료 (MIT 오픈소스) |
| 주목할 가치 | 전체 PDF를 컨텍스트에 넣는 방식 대비 24–51× 토큰 효율 향상(실제 서적 측정 기준). Agent Skills 오픈 표준을 지원해 Claude Code 외 환경에서도 동일한 스킬 재사용 가능. 사내 문서·디자인 시스템·API 스펙 등 비서적 문서에도 적용 가능 |

**유사 카테고리 비교** (문서 → 에이전트 스킬 변환)

| | book-to-skill | 전체 PDF 컨텍스트 삽입 | 수동 요약 |
|---|---|---|---|
| 토큰 효율 | 24–51× 절약 (측정값) | 기준 (1×) | 가변적 |
| 자동화 | CLI 한 줄 | 없음 | 수동 작업 |
| 호환 에이전트 | Claude Code, Copilot CLI, Amp | 무관 | 무관 |
| 로컬 처리 | ✓ | ✓ | ✓ |

**5분 검증 액션** `npx skills add virgiliojr94/book-to-skill` 로 설치 후, 가지고 있는 기술 PDF 한 권을 `/book-to-skill <path>` 명령으로 변환해 생성된 SKILL.md 구조 확인

**출처** [github.com/virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill) · [booktoskill.is-a.dev 가이드](https://booktoskill.is-a.dev/guide/) · [Mervin Praison 활용기](https://mer.vin/2026/05/turn-a-400-page-book-into-a-claude-code-skill-book-to-skill-guide/)
