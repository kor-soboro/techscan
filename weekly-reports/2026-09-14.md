### 1. [GNAP — Git-Native Agent Protocol](https://github.com/farol-team/gnap)

**무엇** 에이전트 팀이 서버·데이터베이스 없이 git 저장소 하나로 작업을 조율하는 개방형 RFC 초안이다. `agents.json`, `tasks/`, `runs/`, `messages/` 네 가지 구조로 구성되며, git push/pull이 가능한 에이전트라면 언어·프레임워크에 관계없이 참여할 수 있다. git 커밋 이력이 감사 로그를 겸하며, 작업 상태는 `backlog → ready → in_progress → review → done`으로 전이된다.

**쉬운 비유** 팀원이 포스트잇을 붙이고 옮기는 공용 화이트보드를 git 저장소로 대체한 것과 같다. 어떤 팀원(에이전트)이라도 메모를 작성하고 옮길 수 있으며, 변경 이력이 자동으로 남는다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | git 인증(SSH/HTTPS). LLM 호출 방식은 에이전트별로 상이 |
| 비용 | 무료(MIT 라이선스). LLM 호출 비용은 에이전트 구현체에 따라 별도 |
| 주목할 가치 | 이번 주 microsoft/promptflow(#4093), letta-ai/letta(#3226), microsoft/agent-framework(#4715)에 연달아 통합 이슈가 등록됐다. 서버·메시지 브로커 없이 에이전트 간 조율이 가능한 점이 기존 오케스트레이션 프레임워크와 구분되는 지점이며, 현재 Farol Labs가 4개 에이전트·50여 개 작업에 프로덕션 운용 중이라고 밝혔다. |

**유사 카테고리 비교**

| | GNAP | 메시지 큐(Redis/RabbitMQ) | LangGraph / Microsoft Autogen |
|---|---|---|---|
| 인프라 요구 | git만 필요 | 별도 서버 필요 | Python 환경 + 브로커 선택 |
| 감사 로그 | git 이력 자동 포함 | 별도 구성 | 별도 구성 |
| 언어·프레임워크 호환 | git 가능 환경 모두 | 클라이언트 라이브러리 의존 | Python 중심 |
| 오프라인 동작 | 가능 | 불가 | 제한적 |
| 현재 성숙도 | RFC 초안 (84★) | 성숙 | 성숙 |

**5분 검증 액션** `github.com/farol-team/gnap` README의 "How It Works" 섹션을 읽고, `board/` 디렉터리 구조 예시를 확인한다. 이어서 microsoft/promptflow 이슈 #4093을 보면 실제 프레임워크 팀이 어떤 부분을 통합 포인트로 검토하는지 파악할 수 있다.

### 2. [Geiger — AI 에이전트 인벤토리 스캐너](https://github.com/Atomburstofficial/geiger)

**무엇** 로컬 머신에 설치된 AI 에이전트·MCP 서버·플러그인·확장을 열거하고, 각 항목이 어떤 권한(파일시스템, 네트워크, 시크릿 등)을 보유하는지 레이블로 표시하는 읽기 전용 스캐너다. 설치 없이 `npx geiger-scan`으로 실행되며, 결과를 터미널·HTML·JSON으로 출력한다. Claude Code/Desktop, Cursor, Windsurf, VS Code 등 주요 MCP 호스트를 지원하고, 기준선 비교(드리프트 감지)와 CI/CD 엄격 모드도 제공한다.

**쉬운 비유** 집에 켜진 전등이 몇 개인지, 각각 어느 방 콘센트에 연결됐는지 한 번에 보여 주는 회로 점검표와 같다. 전등을 끄거나 켜지는 않고 현황만 알려 준다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 인증 불필요 (로컬 설정 파일 스캔, 외부 통신 없음) |
| 비용 | 무료(MIT 라이선스, 텔레메트리 없음) |
| 주목할 가치 | Hacker News에서 9월 10일 주목받았다. 실행 격리 없이 다수의 에이전트·MCP 서버를 동시에 운용하는 환경이 늘면서, 어떤 에이전트가 어떤 범위에 접근하는지 파악하기 어려워진 문제에 직접 대응하는 도구다. `EXECUTES`, `HOLDS-SECRETS`, `BROAD-FILESYSTEM` 등 표준화된 노출 레이블을 통해 위험도를 빠르게 파악할 수 있다. |

**유사 카테고리 비교**

| | Geiger | Snyk Agent Scan | 수동 설정 파일 점검 |
|---|---|---|---|
| 설치 | `npx geiger-scan` (런타임 의존성 없음) | `npm i -g snyk` + 계정 필요 | 없음 |
| 스캔 범위 | 에이전트·MCP·플러그인·확장 | MCP 서버·에이전트 스킬 보안 취약점 | 수동 |
| 주요 출력 | 권한·노출 레이블 인벤토리 | 보안 취약점(프롬프트 인젝션 등) | 해당 없음 |
| 네트워크 전송 | 없음 | Snyk 서비스로 결과 전송 | 없음 |
| CI/CD 통합 | 엄격 모드 지원 | 지원 | 해당 없음 |

**5분 검증 액션** `npx geiger-scan`을 실행한 뒤 터미널 출력에서 `BROAD-FILESYSTEM` 또는 `EXECUTES` 레이블이 붙은 항목을 확인한다. 예상보다 많은 범위를 가진 MCP 서버·플러그인이 있다면 설정 파일에서 해당 범위를 좁히는 것을 검토한다.
