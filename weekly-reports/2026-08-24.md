### 1. [DeepSeek Harness v0.1](https://github.com/deepseek-ai/deepseek-harness)

**무엇** DeepSeek가 MIT 라이선스로 공개한 에이전트 런타임 프레임워크. 모델·도구·세션·샌드박스·스토리지·인터페이스를 포함한 모든 컴포넌트를 플러그인으로 교체할 수 있는 구조를 채택했다. 현재 v0.1 개발자 프리뷰 상태이며, DeepSeek V4 시리즈 모델을 기본 백엔드로 사용하되 플러그인으로 다른 모델로 교체할 수 있다.

**쉬운 비유** 레고 조립 키트처럼 본체(런타임)는 두고 두뇌(모델)·손(도구)·기억(스토리지)을 필요에 따라 마음대로 교체할 수 있다. 기존 도구들은 일부 부품을 고정 부품으로 다루는 반면, 이 프레임워크는 어느 부품이든 뺄 수 있다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | DeepSeek API key (BYOK) / 플러그인 교체로 다른 LLM 제공자 API key 사용 가능 |
| 비용 | 무료 (MIT 오픈소스, LLM 호출 비용 별도) |
| 주목할 가치 | 유사 프레임워크들이 세션·샌드박스를 고정 레이어로 다루는 것과 달리, 이 두 레이어까지 플러그인 교체 대상으로 확장한 점이 구조적 차별점. 출시 4일 만에 13만 5천 GitHub 스타를 기록하며 에이전트 하네스 카테고리 중 가장 빠른 초기 채택 속도를 보였다. |

**유사 카테고리 비교** (에이전트 런타임/하네스 프레임워크)

| | DeepSeek Harness v0.1 | Microsoft Agent Framework 1.0 | LangGraph |
|---|---|---|---|
| 라이선스 | MIT | MIT | MIT |
| 플러그인 교체 범위 | 모델·도구·세션·샌드박스·스토리지 전체 | 모델·도구·세션 | 도구·그래프 노드 |
| MCP 네이티브 지원 | 플러그인으로 추가 | 네이티브 지원 | 커뮤니티 플러그인 |
| 성숙도 | v0.1 개발자 프리뷰 | GA (v1.0) | 안정화 릴리스 |

**5분 검증 액션** GitHub 저장소 README의 Architecture 또는 Plugin System 섹션만 읽어 플러그인 인터페이스 정의 방식과 기존 도구와의 교체 방법 파악.

### 2. [Cloudflare Kitesurf](https://developers.cloudflare.com/kitesurf/)

**무엇** Cloudflare가 에이전트 전용으로 설계해 발표한 브라우저 런타임. Chromium 대비 CPU·메모리 사용량을 3~7배 줄이면서 23만 5천 개 이상의 웹 플랫폼 테스트를 통과한다. Cloudflare Workers 플랫폼 위에서 동작하므로 서버리스 에이전트 환경에 직접 연결할 수 있다.

**쉬운 비유** 짐 배달 전용으로 설계된 소형 화물차처럼, 사람이 보는 브라우저와 같은 기능을 유지하면서 로봇(에이전트)이 반복 작업을 처리하기에 최적화한 가벼운 버전이다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Cloudflare 계정 필요 |
| 비용 | Cloudflare Workers 플랫폼 과금 구조 적용 (세부 에이전트 브라우저 요금 미공개) |
| 주목할 가치 | Playwright·Selenium 기반 Chromium 구동 방식의 높은 자원 비용이 에이전트 스케일 아웃의 병목으로 꼽혀 온 상황에서, 인프라 레벨에서 이를 직접 해소하려는 시도. Cloudflare 엣지 인프라와의 통합으로 레이턴시 최적화도 함께 제공된다. |

**5분 검증 액션** Cloudflare 개발자 블로그에서 Kitesurf 발표 포스트를 찾아, 기존 Playwright 코드를 그대로 쓸 수 있는지(호환성) 여부와 Workers 요금 구조 확인.

### 3. [Task-CoEvolve](https://arxiv.org/abs/2608.20169) — 하네스 최적화 평가 비용 80% 절감 기법

**무엇** LLM 에이전트 하네스(도구 구성·프롬프트 조합 등)를 최적화할 때 발생하는 평가 비용을 줄이는 방법론. 후보 하네스들이 서로 다른 답을 내는 "판별력 있는 태스크"를 집중 선별해 평가하는 분산 기반 적응형 샘플링을 핵심 기법으로 사용한다. Terminal-Bench 2.1 기준, 평가 횟수를 80% 줄이면서 full-set 탐색과 동등한 최종 성능을 달성했다.

**쉬운 비유** 시험 준비 시 전체 문제집을 다 풀지 않고, 맞히기도 틀리기도 하는 "경계선 문제"에만 집중해 약점을 빠르게 파악하는 전략 — 그 선별 자체를 자동화한 것이다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 해당 없음 (학술 논문, 코드 오픈소스 공개 예정) |
| 비용 | 무료 (코드: github.com/Agent4Science-UTokyo/Task-CoEvolve 공개 예정) |
| 주목할 가치 | 하네스 구성 탐색 비용(토큰·시간)이 실무 병목으로 부상하는 시점에 평가 효율화 기법을 제안. 논문 기준 토큰 사용량 67~80%, 탐색 시간 약 50% 절감. 구현이 기존 탐색 루프에 샘플링 레이어를 추가하는 방식으로 비교적 도입이 단순하다. |

**5분 검증 액션** arXiv 논문 Abstract와 Section 3 (Adaptive Validation Task Selection) 을 읽어 샘플링 기준과 구현 복잡도 파악.
