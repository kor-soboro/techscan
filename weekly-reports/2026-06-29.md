## 👀 지금 살펴볼 가치

### 1. [Mastra @mastra/core@1.46.0](https://github.com/mastra-ai/mastra/releases) — Multi-session 하네스 팩토리 아키텍처

**무엇**
6월 24일 릴리스된 Mastra의 메이저 아키텍처 전환. 기존의 싱글턴 세션 모델(`harness.session`)을 팩토리 기반(`harness.createSession()`)으로 교체해 격리된 세션을 동적으로 생성할 수 있게 됐다. 동시 다중 사용자 / 다중 스레드 호스팅을 공식 지원하며, HTTP 기반 하네스 세션 라우팅과 분산 리싱(leasing), Next.js App Router 어댑터, TanStack Start 어댑터도 함께 추가됐다. Breaking Change가 포함되어 있어 v1.45 이하 코드베이스는 마이그레이션 필요.

**쉬운 비유**
기존에는 상담 창구가 하나뿐이어서 손님이 한 명씩만 처리됐다면, 이제는 독립된 창구를 필요한 만큼 열어 여러 손님을 동시에 응대할 수 있게 된 것.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 사용자가 직접 LLM 공급자 API 키 제공 (BYOK; Anthropic, OpenAI, Groq 등 다중 공급자 지원) |
| 비용 | 무료 (오픈소스, LLM 호출 비용 별도) |
| 주목할 가치 | 에이전트 서버를 프로덕션에서 다중 사용자에게 제공할 때 세션 병목이 구조적으로 제거됨. 기존 버전과 Breaking Change가 있으므로 v1.45 이하 사용자는 CHANGELOG의 마이그레이션 가이드 확인 필수 |

**유사 카테고리 비교**

| | Mastra @1.46.0 | LangGraph (LangChain) | DeepAgents |
|---|---|---|---|
| 주 언어 | TypeScript | Python | Python |
| 멀티 세션 공식 지원 | v1.46.0부터 | LangGraph Platform 별도 구성 | 명시적 지원 미확인 |
| 라이선스 | 오픈소스 | MIT | MIT |
| 특징 | 팩토리 세션 + 어댑터 생태계 | 그래프 기반 오케스트레이션 | 즉시 사용 가능한 번들 하네스 |

**5분 검증 액션**
GitHub Releases 페이지에서 `@mastra/core@1.46.0` 릴리스 노트 클릭 → Breaking Changes 항목에서 `harness.session` 제거 및 `harness.createSession()` 전환 내용 확인 → 기존 프로젝트가 영향을 받는지 grep으로 `harness.session` 패턴 검색.

### 2. [Deep Agents v0.6.12](https://github.com/langchain-ai/deepagents) — LangChain의 번들 에이전트 하네스

**무엇**
LangGraph 위에서 동작하는 LangChain의 의견이 담긴(opinionated) 에이전트 하네스. 6월 25일 v0.6.12 출시. 서브에이전트 위임(격리 컨텍스트), 파일시스템 조작(읽기·쓰기·편집·검색), 컨텍스트 자동 오프로딩, 자동 요약, Human-in-the-loop 도구 승인, 재사용 가능한 스킬을 한 패키지로 제공한다. 도구 호출(tool calling)을 지원하는 모든 LLM과 호환.

**쉬운 비유**
개별 주방 도구를 따로 구입하는 대신 칼·도마·냄비·정리함이 모두 포함된 요리사 세트를 구매하는 것. 바로 요리를 시작할 수 있지만, 이미 가지고 있는 도구와 중복이 생길 수 있다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 사용자가 직접 LLM 공급자 API 키 제공 (BYOK) |
| 비용 | 무료 (오픈소스 MIT, LLM 호출 비용 별도) |
| 주목할 가치 | 25.2k GitHub 스타 / 3.6k 포크. LangGraph 에코시스템에서 현재 feature-complete 수준이 가장 높은 단일 하네스 중 하나. 단일 에이전트 워크플로에서 다중 에이전트 위임으로 넘어갈 때의 진입 비용이 낮음 |

**유사 카테고리 비교**

| | Deep Agents | OpenHarness (HKUDS) | agent-harness-generator (ruvnet) |
|---|---|---|---|
| 생태계 | LangChain / LangGraph | 독립 | 멀티 하네스 스캐폴딩 |
| 주 언어 | Python | Python / TypeScript | JavaScript / npm |
| GitHub 스타 | 25.2k | 14.2k | 342 |
| 라이선스 | MIT | MIT | MIT |
| 스타일 | 즉시 사용 (opinionated) | 코어 인프라 + 개인 에이전트 Ohmo 번들 | 커스텀 하네스 생성기 |
| 최신 버전 | v0.6.12 (6/25) | v0.1.9 (5/7) | v0.1.3 (6/14) |

**5분 검증 액션**
GitHub README의 Quick Start 예제에서 서브에이전트 위임 코드 블록 확인. `DEEP_AGENTS_DEBUG=1` 환경 변수를 켜면 에이전트 간 컨텍스트 전달 흐름을 로그로 확인할 수 있다.

**출처**
- [langchain-ai/deepagents](https://github.com/langchain-ai/deepagents)

## 📝 인지만 해두면 OK

- **[OpenAI GPT-5.6 프리뷰](https://openai.com/index/previewing-gpt-5-6-sol/)** (6월 26일) — Sol(플래그십), Terra(균형), Luna(저비용) 3계층. API 프리뷰를 약 20개 파트너 조직에만 제공 중. ChatGPT에는 미제공, GA 일정 미발표. 가격은 Sol $5/$30, Terra $2.50/$15, Luna $1/$6(백만 토큰 기준)으로 알려짐. 대부분의 에이전트 개발자는 아직 직접 접근 불가.

- **[Claude Code Artifacts 베타](https://code.claude.com/docs/en/whats-new)** — Team/Enterprise 플랜에서 세션 출력을 claude.ai의 공유 가능한 라이브 페이지로 변환하는 기능이 베타 오픈. 에이전트 결과물을 팀과 공유하는 워크플로에 유용하나 현재 개인 플랜 미지원.

- **[Mastra Durable Agents](https://github.com/mastra-ai/mastra)** (6월 26일) — v1.46.0 사이클의 추가 기능. 클라이언트 연결 끊김·브라우저 새로고침 시에도 스트림이 유지되는 재개 가능(resumable) 스트림 지원. 장기 실행 에이전트 작업의 안정성에 직접적인 영향을 준다.

- **[Vercel AI SDK — DeepAgents & OpenCode 어댑터 추가](https://vercel.com/changelog/deepagents-and-opencode-harness-adapters)** — HarnessAgent API에 Deep Agents와 OpenCode(Codex 기반) 어댑터가 새로 추가됨. 동일한 인터페이스 코드에서 하네스 교체가 단순해지는 패턴. 이전에 공개된 Claude Code, Codex, Pi 어댑터에 이어 선택지가 확대됨.

- **[GPT-4.5 ChatGPT 제거](https://openai.com/index/previewing-gpt-5-6-sol/)** (6월 26일) — ChatGPT 및 Custom GPTs에서 GPT-4.5 모델이 제거됨. 기존 대화는 GPT-5.5로 자동 전환. API 코드에서 모델 ID를 하드코딩한 경우엔 영향 없으나, ChatGPT 기반 워크플로 사용자는 동작 변화를 확인할 필요 있음.
