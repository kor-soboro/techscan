### 2. [Microsoft Agent Framework: Agent Harness + CodeAct](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-at-build-2026-announce/) — Build 2026 발표

**무엇**
Microsoft Build 2026(6월 초)에서 발표된 MAF(Microsoft Agent Framework)의 신규 기능 묶음. **Agent Harness**는 컨텍스트 압축·명령 병합·할 일 추적 같은 생산 환경 패턴을 프레임워크 기본값으로 포함한다. **CodeAct**는 여러 도구 호출을 단일 Python 프로그램으로 묶어 Hyperlight 마이크로 VM에서 격리 실행하며, 레이턴시 ~50% · 토큰 사용량 ~60% 절감을 주장한다. **Hosted Agents**는 Foundry Agent Service를 통해 로컬 개발 → 관리형 프로덕션 배포를 직접 연결한다.

**쉬운 비유**
배달 기사가 주문 건마다 가게를 한 번씩 방문하는 대신, 한 번 이동에 묶음 배달을 처리하고 냉장·냉동 칸이 분리된 특수 가방(격리 VM)에 담아 오는 것과 같다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Azure 구독 + Azure Entra(Microsoft Foundry Hosted Agents 사용 시); 로컬 개발은 오픈소스 MAF SDK 단독 사용 가능 |
| 비용 | MAF SDK 자체는 오픈소스(MIT); Foundry Hosted Agents는 Azure 과금(상세 미공개) |
| 주목할 가치 | AutoGen + Semantic Kernel 통합 후 첫 번째 생산 패턴 표준화 발표. CodeAct 패턴은 다른 에이전트 프레임워크에도 이미 존재하지만(Qwen·Claude 계열 실험 포함), MAF가 Hyperlight 격리와 결합해 공식 패키지로 제공한 것은 처음이다. |

**유사 카테고리 비교** (에이전트 실행 하네스)

| | MAF Agent Harness | Claude Agent SDK | Goose (AAIF) |
|---|---|---|---|
| 코드 실행 격리 | Hyperlight 마이크로 VM | 미포함(플러그인 별도) | 샌드박스 확장 가능 |
| 멀티 에이전트 | Handoff + A2A | 내장 | 외부 조율 |
| 클라우드 호스팅 | Azure Foundry | Anthropic 관리 | 자체 호스팅 |

**5분 검증 액션**
[CodeAct Microsoft Learn 문서](https://learn.microsoft.com/en-us/agent-framework/agents/code_act)에서 `HyperlightCodeActProvider` 코드 예시를 확인하고, GitHub Discussions #5328에서 알파 피드백 흐름 파악.

### 3. [anthropics/skills](https://github.com/anthropics/skills) — Agent Skills 오픈 표준 생태계 현황

**무엇**
Anthropic이 도입한 SKILL.md 포맷 기반의 에이전트 스킬 오픈 표준 저장소. 2026년 6월 11일 기준 ~149k GitHub 스타, ~17.6k 포크로 2월(~73k) 대비 두 배 이상 성장. GitHub Copilot · Claude Code · Cursor · Gemini CLI · JetBrains Junie · Goose · OpenCode · Amp · Kiro 등 약 40개 클라이언트가 호환된다고 공식 목록에 명시돼 있다.

**쉬운 비유**
플러그인 단자 규격이 하나로 통일된 것처럼, 어떤 AI 도구든 같은 '규격 설명서 파일' 하나로 전문 지식을 공유받을 수 있는 상태가 됐다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 — 파일 기반 로컬 참조 |
| 비용 | 무료(오픈소스) |
| 주목할 가치 | 단일 저장소에서 관리되던 스킬들이 이제 Angular · analogjs · hereandnowai 등 외부 조직의 파생 저장소로 확산되고 있어, 사실상 에이전트 도메인 지식 패키지 생태계의 초기 형태가 형성되고 있다. |

**5분 검증 액션**
[Agent Skills Specification — DeepWiki](https://deepwiki.com/anthropics/skills/6.1-agent-skills-specification)에서 SKILL.md 프론트매터 구조와 `references/` · `scripts/` 디렉터리 규약을 확인. 그다음 `angular/skills`를 예시로 실제 파일 구조 비교.

## 📝 인지만 해두면 OK

- **[Kimi K2.7-Code](https://cryptobriefing.com/kimi-k2-7-code-open-source-release/)** — Moonshot AI가 6/12 공개한 1조 파라미터 MoE 코딩 모델(32B 활성, 256K 컨텍스트, 수정 MIT). 자율 코딩 에이전트용으로 설계됐으며 K2.6 대비 추론 토큰 ~30% 절감. 오픈 모델 목록 관리 차원에서 기록해 둘 만하지만, 이미 유사 성능대의 경쟁 모델이 다수 존재해 즉각 도입 유인은 제한적이다.

- **[Goose → AAIF(Linux Foundation) 이관](https://aitoolly.com/ai-news/article/2026-06-11-goose-an-open-source-and-extensible-ai-agent-redefining-the-software-development-lifecycle)** — Block 주도의 오픈소스 AI 에이전트 Goose가 6월 중 Linux Foundation 산하 Agentic AI Foundation(AAIF) 거버넌스 체계로 이전됐다(저장소: `aaif-goose/goose`). 15개 이상 LLM 프로바이더 지원, Skills 호환. 단일 회사 프로젝트에서 중립 재단 프로젝트로 전환된다는 점에서 장기 신뢰도가 높아졌으나, 기능 자체는 크게 바뀌지 않아 '인지'로 충분하다.

- **[OpenAI Agent Builder / Evals 종료 예고](https://openai.com/index/introducing-agentkit/)** — OpenAI가 6/3 Agent Builder와 Evals 제품을 2026년 11월 30일부로 종료한다고 발표. 이후 코드 기반 워크플로는 Agents SDK로, 자연어 기반 워크플로는 ChatGPT Workspace Agents로 전환을 권고. 현재 Agent Builder를 쓰고 있다면 마이그레이션 경로를 미리 확인할 필요가 있다.

- **[MCP 2026 Spec RC — 상태 없는 서버 + Server Cards](https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/)** — 5/21 확정된 RC 기반으로 7/28 최종 스펙 발행 예정. 상태 없는 HTTP 서버 아키텍처(라운드로빈 LB 지원), Server Cards 자동 탐색, MCP Apps(서버 렌더링 UI 확장), Tasks 확장(장기 실행 작업), A2A 연동이 포함된다. 현재 프로덕션 MCP 서버를 운영 중이라면 마이그레이션 영향을 미리 파악해 두는 것이 좋다.
