## 👀 지금 살펴볼 가치

### 1. [Microsoft Orchard](https://github.com/microsoft/Orchard)

**무엇** Microsoft Research가 공개한 에이전트 학습·평가·롤아웃 통합 프레임워크. Kubernetes 기반 샌드박스 환경(Orchard Env)과 강화학습 트레이너를 하나의 플랫폼에서 제공하며, 소프트웨어 엔지니어링(Orchard-SWE), 브라우저 내비게이션(Orchard-GUI), 개인 비서(Orchard-Claw) 세 가지 도메인용 레시피를 내장한다. 107K개 SWE 궤적 데이터셋과 3,070개 GUI 롤아웃 데이터셋도 Hugging Face에 함께 공개됐다.

**쉬운 비유** 신입 직원을 실제 고객 앞에 내보내기 전에, 다양한 업무 시나리오가 마련된 모의 사무실에서 반복 훈련시키고 그 결과를 채점까지 해주는 훈련장 한 세트를 공짜로 받는 것과 같다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 셀프호스팅 Kubernetes 클러스터 + SANDBOX_API_KEY (환경 변수) |
| 비용 | 무료 (MIT 오픈소스, 인프라 비용 별도) |
| 주목할 가치 | SWE-bench Verified에서 약 3B 활성 파라미터로 69.7% 달성(리랭킹 시 73%) — 10배 이상 큰 모델과 동급 수준임이 보고됨. 관리형 샌드박스(E2B·Daytona) 대비 스팟 인스턴스 기준 약 10배 저렴한 비용으로 운용 가능하다고 발표됨 |

**유사 카테고리 비교** (에이전트 학습·평가 인프라)

| | Microsoft Orchard | E2B | Daytona |
|---|---|---|---|
| 학습·평가 일체 제공 | ✓ | 제한적 | 제한적 |
| 샌드박스 방식 | Kubernetes 네이티브 셀프호스팅 | 관리형 클라우드 | 관리형 클라우드 |
| 비용 구조 | 인프라 직접 운용 | 사용량 기반 과금 | 사용량 기반 과금 |
| 라이선스 | MIT | 독점 | 독점 |
| 공개 학습 데이터 | ✓ (107K 궤적) | — | — |

**5분 검증 액션** [GitHub 레포](https://github.com/microsoft/Orchard) README의 'Getting Started' 섹션 및 `orchard_env/` 폴더 구조 확인, Hugging Face의 107K SWE 궤적 데이터셋 카드 열람

## 📝 인지만 해두면 OK

- **[OpenAI GPT-5.6 Sol 업데이트 + 추론 슬라이더](https://openai.com/index/improving-gpt-5-6-sol-in-chatgpt/)** (8/6) — Plus·Pro 구독자 대상으로 응답당 추론 깊이를 조절하는 슬라이더가 추가됐고, OpenAI 내부 평가 기준 사실 오류가 68% 감소했다고 발표됨. 동시에 Free 플랜에 GPT-5.6 Luna를 제공하고 텍스트 채팅 무제한으로 전환. ChatGPT Work·Codex에 쓰이는 Sol 버전은 이번 변경 대상 외. 에이전트 백엔드 모델로 사용 중이라면 자체 워크로드 기준 별도 검증 필요

- **[EU AI Act 고위험 AI 시스템 의무 발효](https://www.cooley.com/news/insight/2026/2026-08-03-eu-ai-act-transparency-obligations-take-effect-2-august-2026/)** (8/2 기준) — 챗봇이 AI임을 이용자에게 고지해야 하는 투명성 의무(Article 50), 딥페이크 콘텐츠 레이블 의무, 고위험 AI 시스템의 감사 로그·인간 감독·리스크 관리 문서화 의무가 발효됨. 미준수 시 최대 1,500만 유로 또는 전 세계 연매출 3% 제재 가능. EU 이용자를 대상으로 하는 에이전트·챗봇 서비스라면 즉시 적용 여부 확인이 필요

- **[EvoHarness-RL: 자기 진화 런타임 하네스](https://arxiv.org/abs/2608.05446)** (arXiv 2608.05446, August 2026) — 에이전트 하네스의 외부 상태 접근 정책(Belief·Progress·Experience 세 요소) 자체를 강화학습으로 학습하는 방식 연구. Qwen3-8B 기반 ALFWorld에서 96.9% 달성. '하네스 어닐링(harness annealing)' 현상 — 학습이 진행될수록 외부 상태 호출이 줄고 모델 내부 정책으로 흡수되는 현상 — 을 식별. 즉시 프로덕션 적용 대상보다는 하네스 정책 설계 방향성의 참고 자료로 적합
