## 👀 지금 살펴볼 가치

### 1. [herdr](https://github.com/ogulcancelik/herdr)

**무엇** 터미널에서 여러 AI 코딩 에이전트를 동시에 실행·모니터링하는 Rust 기반 에이전트 멀티플렉서. Claude Code, GitHub Copilot, Devin 등 15종 이상 지원하며, 각 에이전트에 실제 터미널 세션을 할당한다.

**쉬운 비유** 여러 직원이 각자 방에서 일하는 사무실에서, 복도 한쪽 패널 하나로 "이 방 막힘🔴 / 저 방 작업 중🟡 / 완료🔵"를 한눈에 확인하는 관리자 보드. 직원을 교체하거나 직접 들어가지 않아도 흐름 전체가 보인다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (herdr 자체는 계정·API 키 불필요; 에이전트 별 개별 인증은 각 도구 설정 따름) |
| 비용 | 무료 오픈소스 (AGPL-3.0 또는 상용 라이선스 선택); 약 10MB 단일 바이너리 |
| 주목할 가치 | 에이전트 상태(blocked/working/done/idle)를 소켓 API로 외부에서 참조·오케스트레이션 가능. tmux나 화면 분할과 달리 에이전트의 의미론적 상태를 프로토콜 레벨에서 노출. SSH 원격 연결·세션 재연결 지원 |

**유사 카테고리 비교**

| | herdr | tmux + 수동 모니터링 | 상용 에이전트 대시보드 |
|---|---|---|---|
| 에이전트 상태 인식 | ✅ 내장 | ❌ 없음 | ✅ (벤더별 상이) |
| 소켓 API 오케스트레이션 | ✅ | ❌ | 일부만 |
| 로컬 실행 (단일 바이너리) | ✅ | ✅ | 클라우드 의존 |
| 비용 | 무료/오픈소스 | 무료 | 유료 |

**5분 검증 액션** README의 "State Indicators" 섹션 확인 → `herdr` 바이너리 설치 후 기존 Claude Code 세션 attach → 소켓 API 예시 한 줄로 상태 읽기 테스트

**출처** [GitHub — ogulcancelik/herdr](https://github.com/ogulcancelik/herdr)

### 2. [page-agent](https://github.com/alibaba/page-agent)

**무엇** 웹 페이지 내부에 삽입되어 자연어 명령으로 DOM을 직접 조작하는 인페이지 GUI 에이전트 라이브러리(Alibaba). 스크린샷 없이 텍스트 기반 DOM 처리, MCP 서버 베타 포함.

**쉬운 비유** 웹 페이지에 보이지 않는 심부름꾼을 심어두는 것. "장바구니에 담아줘"라고 말하면 알아서 클릭하고 폼을 채운다. 별도 프로그램 설치나 추가 서버 없이 JavaScript 코드 한 줄 삽입으로 동작.

| 라벨 | 값 |
|---|---|
| 인증 방식 | BYOK (LLM API 키; baseURL + apiKey 직접 설정) |
| 비용 | 무료 오픈소스 (MIT); LLM 호출 비용 별도 |
| 주목할 가치 | 브라우저 확장·Python 서버·헤드리스 브라우저 없이 클라이언트 사이드 JS로 동작. MCP 서버 베타를 통해 외부 에이전트가 이 라이브러리가 삽입된 페이지를 원격 제어 가능. 평가용 데모 LLM API를 기본 제공해 초기 키 없이도 테스트 가능 |

**유사 카테고리 비교**

| | page-agent | browser-use | Puppeteer/Playwright |
|---|---|---|---|
| 실행 위치 | 페이지 내 JS (클라이언트) | 서버 사이드 Python | 서버 사이드 Node.js |
| 브라우저 별도 권한 | 불필요 | 필요 | 필요 |
| MCP 서버 포함 | ✅ (베타) | 일부 지원 | ❌ |
| 라이선스 | MIT | MIT | Apache-2.0 |

**5분 검증 액션** README Quick Start의 데모 API 옵션으로 LLM 키 없이 기본 동작 확인 → Chrome 확장 설치 후 실제 페이지에서 자연어 명령 1회 실행

**출처** [GitHub — alibaba/page-agent](https://github.com/alibaba/page-agent)

- **[Mastra Harness](https://mastra.ai/blog/announcing-agent-harness)** — TypeScript AI 프레임워크 Mastra의 신규 Harness 프리미티브(6월 중순 발표). 세션·모드 전환·툴 승인·서브에이전트 위임·35종 이벤트 pub/sub 포함. TypeScript 기반 에이전트 스택을 구축 중이라면 Mastra Harness 레퍼런스 페이지 확인 권장.

- **[MCP 2026 로드맵](https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/)** — 4대 우선순위 공개: ① 스테이트리스 HTTP 전송(스티키 세션 제거) ② 에이전트 간 Tasks 통신(재시도·만료 정책) ③ 거버넌스 Working Group 위임 ④ 엔터프라이즈 준비(SSO·감사 로그). 날짜 명시 없는 Working Group 중심 운영. MCP 기반 프로덕션 배포를 계획 중이라면 방향성 인지 필요.

- **[Claude Science](https://www.anthropic.com/news/claude-science-ai-workbench)** — Anthropic 연구자용 AI 워크벤치 공개 베타(6월 30일). 유전체·단백질구조·화학정보학 등 60개 이상 과학 스킬 사전 구성, macOS/Linux 로컬 및 SSH/HPC 지원. Claude Pro/Max/Team/Enterprise 대상. $30,000 크레딧 지원 프로그램(7월 15일까지 신청). 생물·화학 연구 파이프라인 외에는 직접 적용 범위 제한적.

- **[claude-skills](https://github.com/alirezarezvani/claude-skills)** — 330개 이상 커스터마이즈 가능한 Claude Code 스킬·에이전트 커맨드 모음 레포. 이번 주 GitHub 트렌딩 (20K+ 스타). 에이전트 스킬 레이어를 빠르게 확장하려는 팀에게 참고용 목록으로 유용하나, 자체 도구가 아닌 큐레이션 모음임.

## ⚠️ ToS 제약 가능 카테고리

해당 카테고리는 일부 플랫폼의 third-party OAuth 정책에 따라 사용에 제약이 있을 수 있어 별도로 분류합니다. 도구 사용 전 자신의 상황·계약·정책에 맞는지 확인 필요.

- **[X 공식 MCP 서버](https://cybersecuritynews.com/x-launches-hosted-mcp-servers/)** — 6월 30일 출시. 엔드포인트 `https://api.x.com/mcp`, 200개 이상 API 노출(검색·트렌드·북마크·Articles 게시 등). **인증 방식**: OAuth 2.0 (X Developer Portal 앱 등록 + xurl CLI 브리지 설치 필요). **제약 가능 사항**: X Developer API ToS는 자동화 대량 게시, 콘텐츠 대량 스크래핑을 제한 사항으로 명시하고 있으며, 에이전트 파이프라인이 사용자 개입 없이 자율적으로 게시·대량 요청하는 시나리오에서 약관 저촉 가능성 있음. 사용 전 X Developer 약관 Restricted Use Cases 항목 직접 확인 권장.
