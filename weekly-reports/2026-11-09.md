### 1. [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)

**무엇** Vercel Labs가 10월 28일(v1.0) → 11월 3일(v1.1) 연속 출시한 AI 에이전트 전용 컴퓨터 사용 CLI. Rust + C 라이브러리 구조로 OS 접근성 트리를 읽어 데스크탑 앱을 제어한다. 모델이 내장되지 않아 어느 에이전트 위에도 얹을 수 있다.

**쉬운 비유** 화면을 "눈으로 보는" 대신 앱의 "목차"(버튼·메뉴 이름)를 읽어서 필요한 버튼만 정확히 누르는 방식 — 마치 점자 화면 판독기처럼 앱 구조를 텍스트로 파악한 뒤 클릭 위치를 결정한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (도구 자체는 모델 무관; 에이전트 각자의 LLM API 키 사용) |
| 비용 | 무료(오픈소스 Apache-2.0, LLM 호출 비용 별도) |
| 주목할 가치 | 스크린샷 기반 비전 모델 없이 데스크탑 조작 구현 가능. 비전 모델이 없거나 비용·속도 제약이 있는 에이전트에서 컴퓨터 사용 선택지를 넓힌다. 단일 프로세스로 여러 에이전트가 각자의 커서를 갖고 병렬 실행 가능 |

**유사 카테고리 비교**

| | agent-desktop | Anthropic Computer Use (Claude) | BrowserUse |
|---|---|---|---|
| 제어 방식 | OS 접근성 트리 | 스크린샷 + 비전 모델 | DOM / 브라우저 API |
| 비전 모델 필요 여부 | 불필요 | 필요 | 불필요 |
| 대상 환경 | 모든 데스크탑 앱 | 화면 전체 | 웹 브라우저 |
| 라이선스 | Apache-2.0 | 모델 API 조건 적용 | MIT |

**5분 검증 액션** `aicybr.com` 아키텍처 설명 글에서 접근성 트리 접근 방식의 한계 섹션 확인 → 사용 중인 앱이 접근성 트리를 완전히 노출하는지 점검

### 2. [worktrunk (max-sixty/worktrunk)](https://github.com/max-sixty/worktrunk)

**무엇** 병렬 AI 코딩 에이전트 실행을 전제로 설계된 git 워크트리 관리 Rust CLI. Claude Code·Codex·OpenCode·Gemini CLI 각각에 대한 플러그인이 내장돼 있으며, 브랜치 생성·워크트리 체크아웃·에이전트 실행을 단일 명령어로 묶는다.

**쉬운 비유** 여러 직원이 같은 프로젝트를 동시에 편집할 때 충돌이 나지 않도록, 각자에게 독립된 작업실 사본을 하나씩 나눠주는 방식. 같은 창고(저장소)에서 꺼낸 재료지만 각자 별도 공간에서 조립한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (CLI 도구, 에이전트 인증은 각자 별도) |
| 비용 | 무료(오픈소스; cargo install 또는 Homebrew) |
| 주목할 가치 | 에이전트 병렬 실행 시 발생하는 워크트리 충돌 문제를 에이전트별 플러그인으로 해결한 첫 전용 CLI. Claude Code의 `isolation: "worktree"` 모드와 직접 연동 가능 |

**유사 카테고리 비교**

| | worktrunk | git worktree (기본) | tmux + git 수동 |
|---|---|---|---|
| 에이전트 플러그인 | Claude Code·Codex·OpenCode·Gemini | 없음 | 없음 |
| 명령어 단순성 | 단일 명령어 | 다단계 | 다단계 |
| 커밋 메시지 자동화 | LLM 생성 지원 | 없음 | 없음 |
| 설치 | brew 또는 cargo | git 기본 내장 | 별도 없음 |

**5분 검증 액션** `brew install max-sixty/worktrunk/wt` 후 `wt --help`로 명령어 목록 확인 → README의 "Agent integrations" 섹션에서 사용 중인 에이전트 플러그인 설정법 확인

### 3. [mattpocock/skills](https://github.com/mattpocock/skills)

**무엇** 소프트웨어 개발 실무에서 반복적으로 쓰이는 자동화 패턴을 에이전트 스킬로 패키징한 오픈소스 모음집. 작성자가 실제 사용 중인 `.agents` 디렉터리에서 추출한 Shell 기반 스킬이 중심이다.

**쉬운 비유** 선배 개발자의 사내 치트시트 모음을 에이전트가 바로 불러 쓸 수 있는 스킬 패키지로 묶어놓은 것.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (스킬 파일; 각 스킬 내 도구의 인증은 별도) |
| 비용 | 무료(오픈소스) |
| 주목할 가치 | 연구용 프로토타입이 아닌 실무 사용 중인 스킬 모음이라는 점에서 아이디어 발견 차원에서 가치. 스킬 작성 패턴 참고 자료로도 유효 |

**5분 검증 액션** GitHub 레포의 스킬 목록을 훑어보며 현재 에이전트 워크플로에서 반복되는 작업과 겹치는 스킬이 있는지 확인

## ⚠️ ToS 제약 가능 카테고리

해당 카테고리는 일부 플랫폼의 third-party 자동화 정책에 따라 사용에 제약이 있을 수 있어 별도로 분류합니다. 도구 사용 전 자신의 상황·계약·정책에 맞는지 확인 필요.

- **[milind-soni/OpenMausBot](https://github.com/milind-soni/OpenMausBot)** — "Grok Bots의 오픈소스 대안"으로 소개되어 있으며, VM 내에서 에이전트가 외부 플랫폼(X/Twitter 포함 추정)을 자동화하는 방식으로 작동하는 것으로 보임. 인증 방식 미확인. X(Twitter)를 비롯한 플랫폼의 자동화 접근 금지 조항 또는 bot 정책과 충돌할 가능성이 있으므로, 대상 플랫폼의 이용 약관 확인 후 사용 여부 판단 필요
