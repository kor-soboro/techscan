### 1. [MCP 2026-07-28 Final — 발효 완료, 마이그레이션 시작](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

**무엇** 지난주 리포트에서 RC(Release Candidate) 상태로 소개됐던 MCP 2026-07-28 스펙이 7월 28일 최종 발표됐다. 프로토콜 변경 사항이 공식 확정됐으며 Tier 1 Python·TypeScript SDK가 순차적으로 업데이트 중이다. 이번 주 실무 관점의 핵심은 두 가지다: ① `initialize` 핸드셰이크와 `Mcp-Session-Id`가 제거된 stateless 요청·응답 방식으로의 전환이 확정됐으며, ② Sampling·Roots·Logging 기능의 공식 Deprecated 통보가 SDK에 반영되기 시작했다(최소 12개월 유예 후 제거).

**쉬운 비유** 새 규격의 법 조문이 발효됐다. 예고 기간에 검토만 했다면, 이제는 실제로 무엇을 바꿔야 하는지 내부 점검 목록을 만들 시점이다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 오픈 스펙 (별도 인증 없음), 각 SDK 인증은 프로바이더별 상이 |
| 비용 | 무료 (오픈소스 스펙·SDK) |
| 주목할 가치 | Cloudflare Agents SDK가 Day 0 지원을 선언해 Workers 위에서 MCP 서버를 stateless로 바로 배포 가능. W3C Trace Context 전파 표준화로 분산 추적이 SDK 수준에서 제공됨. `cacheScope`·`ttlMs` 필드 추가로 list 결과 클라이언트 캐싱이 가능해졌다. |

**마이그레이션 확인 포인트**

| 체크 항목 | 영향 |
|---|---|
| `initialize` 핸드셰이크 사용 여부 | 제거 대상 — stateless 방식으로 전환 필요 |
| `Mcp-Session-Id` 헤더 읽기·쓰기 | 제거 대상 |
| Sampling 기능 구현 여부 | Deprecated — 12개월 내 제거 예정 |
| Roots 기능 구현 여부 | Deprecated — 동일 타임라인 |
| Logging 구현 여부 | Deprecated — 동일 타임라인 |

**5분 검증 액션** [MCP 공식 블로그 Final 발표 포스트](https://blog.modelcontextprotocol.io/posts/2026-07-28/)의 "What's Deprecated" 섹션을 읽고, 자체 MCP 서버 코드에서 `initialize`, `Mcp-Session-Id`, `Sampling` 키워드로 전문 검색.

### 2. [DeepSeek V4 Flash 0731](https://aireleasetracker.com/model/deepseek/deepseek-v4-flash-0731)

**무엇** DeepSeek가 7월 31일 공개한 V4 Flash의 재훈련 빌드. 아키텍처(284B 전체 파라미터 / 13B 활성화)와 API 가격은 4월 초 출시분과 동일하나, 에이전트·코딩 벤치마크 점수가 대폭 상승했다고 발표됐다. 특히 에이전트 태스크 특화 지표인 DeepSWE에서 7.3 → 54.4, Terminal Bench 2.1에서 61.8 → 82.7로 공개됐다. V4-Pro-Preview를 포함해 DeepSeek 발표 기준 9개 벤치마크 전항목에서 상위 점수를 기록했다.

**쉬운 비유** 같은 공장, 같은 설비, 동일한 조립 라인인데 원재료 배합 방식만 달리했더니 시험 결과가 두 배 가까이 바뀐 것. 겉으로 보이는 것은 아무것도 바뀌지 않았다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | DeepSeek API key (BYOK) |
| 비용 | $0.14/1M 입력 토큰, $0.28/1M 출력 토큰 |
| 주목할 가치 | 에이전트·코딩 특화 벤치마크에서 비용 대비 최상위 주장. 단, 7월 31일 기준 외부 독립 검증 없음 — 벤더 발표 수치임을 명확히 인지하고 자체 워크로드로 직접 평가 후 투입 결정 권장. |

**유사 카테고리 비교** (저비용 에이전트 모델)
