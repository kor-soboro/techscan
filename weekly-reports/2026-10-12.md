# Weekly AI Agent Tech Scan — 2026-10-12

## 🎯 TL;DR

- **Claude Haiku 5.5**(Oct 7)가 출시됐다. 서브에이전트·브라우저 자동화에 최적화된 저비용 모델로, 이 티어에서 처음으로 조정 가능한 추론 깊이(effort control)를 지원한다.
- **Microsoft Agent Framework Python 1.20.0**(Oct 2)이 네이티브 컴퓨터 사용(computer-use) 지원과 새로운 벡터 스토어 커넥터를 추가했다. 4월에 1.0이 출시된 이후 첫 주요 마이너 업데이트다.
- **claude-mem v13**이 이번 주 GitHub 트렌딩 상위권을 유지했다. 코딩 에이전트 세션 간 기억을 자동으로 압축·주입하는 도구로 Claude Code 외 다섯 종 에이전트를 지원한다.
- **AI 에이전트 무한 루프 차단** 카테고리가 형성됐다. 에이전트 요청 경로에 끼어 반복 호출을 탐지·차단하는 역방향 프록시 도구들이 잇달아 등장했다.
- **MCPCon North America**(Oct 22)가 2주 앞으로 다가왔다. MCP Tasks Extension·MCP Apps의 실제 구현 사례가 발표될 예정이다.

### 1. [Claude Haiku 5.5](https://www.anthropic.com/claude/haiku)

**무엇** Anthropic이 10월 7일 출시한 경량 모델. 요약·분류·서브에이전트·브라우저 조작 등 고빈도 단순 작업용으로 설계됐다. 전임 Haiku 4.5 대비 평균 75% 저렴하며, 이 가격대 모델 중 처음으로 요청별로 추론 깊이를 조절하는 effort control을 지원한다.

**쉬운 비유** 팀에서 단순 업무를 빠르게 처리하는 직원에게 필요할 때만 집중 사고 모드를 켜도록 선택권을 주는 것과 같다. 간단한 일은 빠르게, 판단이 필요한 일은 조금 더 신중하게 처리할 수 있다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Anthropic API key (BYOK) / Claude.ai 구독 (Free·Pro·Max·Team·Enterprise) |
| 비용 | $0.10/$0.50 per million tokens (입력/출력, 100K 토큰 이하 프롬프트 기준); 100K 초과 시 $0.50/$2.50 |
| 주목할 가치 | OSWorld 2.1 오프라인 서브셋 기준 72.4%(Haiku 4.5는 15.7%) — 브라우저 자동화·컴퓨터 사용 작업에서 큰 폭의 개선이 있다. Effort control을 통해 동일 모델로 속도와 추론 깊이를 요청 단위로 트레이드오프할 수 있어 서브에이전트 비용 관리에 활용도가 높다 |

**유사 카테고리 비교**

| | Claude Haiku 5.5 | GPT-4o mini (latest) | Gemini Nano Banana 2.1 |
|---|---|---|---|
| 컨텍스트 창 | 1M 토큰 | 128K 토큰 | 미확인 |
| Effort control | 지원 (첫 경량 모델) | 미지원 | 미확인 |
| 입력 가격(100K↓) | $0.10/M | 미확인 | 미확인 |
| 브라우저 자동화 벤치마크 | OSWorld 2.1: 72.4% | 미확인 | 미확인 |

**5분 검증 액션** Anthropic 공식 문서에서 effort control 파라미터 사용법을 확인한 뒤, 기존 서브에이전트 코드에서 `thinking: {type: "enabled", budget_tokens: N}` 적용 범위를 파악한다. Claude Code에서는 바로 사용 가능하다.

### 2. [Microsoft Agent Framework Python 1.20.0](https://github.com/microsoft/agent-framework/releases)

**무엇** Microsoft의 공개 에이전트 스캐폴딩 프레임워크. 4월 1.0 GA(MCP·A2A 네이티브, 장기 지원 약속)에 이어 10월 2일 1.20.0이 출시됐다. 이번 릴리스의 핵심 추가 기능은 네이티브 컴퓨터 사용(computer-use) 지원, Azure Foundry 호스팅 구조 개편, DuckDB·SQL Server 벡터 스토어 커넥터 추가다. .NET 버전도 dotnet-1.24.0이 함께 출시됐다(보안·세션 처리 안정성 개선).

**쉬운 비유** 건물 관리 시스템에 비유하면, 기존에는 설계도(에이전트 구조)만 다뤘다면, 이번에는 건물 안 컴퓨터를 직접 조작하는 관리인 기능이 내장됐다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | BYOK (Azure OpenAI, Anthropic API key, 로컬 LLM 등 — 커넥터 선택에 따름) |
| 비용 | 무료(오픈소스, MIT 라이선스) — LLM 호출 비용 별도 |
| 주목할 가치 | MCP·A2A가 1.0부터 네이티브 지원되어 외부 라이브러리 없이 표준 에이전트 간 통신이 가능하다. 컴퓨터 사용 지원 추가로 브라우저·GUI 자동화를 동일 프레임워크 안에서 처리할 수 있게 됐다 |

**유사 카테고리 비교**

| | MS Agent Framework 1.20 | LangGraph | CrewAI 1.15 |
|---|---|---|---|
| MCP 네이티브 지원 | ✓ (1.0부터) | 외부 패키지 | 외부 패키지 |
| A2A 지원 | ✓ | 미지원 | 미지원 |
| 컴퓨터 사용 | ✓ (1.20 신규) | 외부 통합 | 외부 통합 |
| 벡터 스토어 커넥터 | DuckDB·SQL Server 추가 | 서드파티 | 서드파티 |
| LTS 약속 | ✓ | 없음 | 없음 |

**5분 검증 액션** [GitHub Releases 페이지](https://github.com/microsoft/agent-framework/releases)에서 1.20.0 체인지로그의 `computer-use` 항목과 `DuckDB connector` 예제 코드를 확인한다.

### 3. [claude-mem v13 — 코딩 에이전트용 세션 간 영구 메모리](https://github.com/thedotmack/claude-mem)

**무엇** 코딩 에이전트 세션 종료 시 활동 내역을 AI로 압축해 저장하고, 다음 세션 시작 시 관련 조각만 자동으로 컨텍스트에 주입하는 플러그인. Claude Code가 1차 타깃이지만 Gemini CLI·Codex·OpenCode·OpenClaw·Copilot도 지원한다. v13.1.0부터 Postgres + BullMQ 기반 팀 서버 배포(server-beta)를 지원한다. 이번 주 GitHub 트렌딩에서 반복 등장했으며, 현재 약 99k 스타를 기록 중이다.

**쉬운 비유** 매번 새 직원이 출근할 때 인수인계 없이 일을 시작하는 것이 아니라, 어제 처리한 사항 요약본이 데스크에 자동으로 놓여있는 것과 같다. 에이전트가 "어제 뭘 했더라"를 처음부터 재파악하는 데 드는 시간을 없앤다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 로컬 파일시스템 기반(기본) / Postgres 서버 모드(팀 배포 시) — 별도 API key 불필요 |
| 비용 | 무료(오픈소스, Apache-2.0) — 메모리 압축 시 LLM 호출 비용 별도 |
| 주목할 가치 | 에이전트 프레임워크 교체 없이 플러그인 형태로 세션 간 기억을 추가할 수 있다. 팀 서버 모드를 통해 여러 개발자가 공유 에이전트 컨텍스트를 운용하는 시나리오까지 확장된다 |

**유사 카테고리 비교**

| | claude-mem v13 | Mem0 | LangMem (LangGraph) |
|---|---|---|---|
| 통합 방식 | 플러그인/훅 (에이전트 교체 불필요) | SDK + API 서버 | LangGraph 내장 |
| 지원 에이전트 | Claude Code, Gemini CLI, Codex 외 | SDK 통합 대상 | LangGraph 기반 |
| 팀 공유 | Postgres 서버 모드 (v13.1+) | 클라우드 API | 미확인 |
| 저장 위치 | 로컬 / 자체 Postgres | 외부 클라우드 | 로컬·외부 선택 |

**5분 검증 액션** `npx claude-mem install` 실행 후, Claude Code 세션 하나를 돌리고 종료한 뒤 생성된 메모리 파일(.claude/memory/)을 열어 압축된 내역이 어떤 형태로 저장되는지 확인한다.

### 4. [NakshGuard / AI 에이전트 루프 차단 카테고리](https://aiindigo.com/blog/nakshguard-deep-dive-technical-review)

**무엇** 에이전트와 LLM 공급자 사이에 끼어드는 역방향 프록시 형태의 안전 도구 카테고리가 이번 주 가시화됐다. 대표 도구로 **NakshGuard**(프록시형, 요청 페이로드 검사 후 반복 패턴 탐지)와 **LoopGuard**(데몬형, Claude Code·Codex·Gemini CLI 세션 실시간 모니터링), **Loopers**(Go, MIT, MCP 툴 콜 결정적 차단기)가 있다. 공통 목표는 에이전트가 동일한 도구 호출 또는 프롬프트를 반복하는 무한 루프 상태를 감지해 자동 차단하는 것이다.

**쉬운 비유** 자동화 공장 라인에서 같은 동작이 비정상적으로 반복되면 비상 정지 버튼이 눌리는 것과 같다. 에이전트가 멈추지 않고 같은 작업을 되풀이할 때 외부에서 강제 중단하는 역할이다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 로컬 배포(에이전트 base URL을 프록시로 변경) — 별도 LLM API key 불필요 |
| 비용 | NakshGuard: 미확인(상업용 가능성 있음) / LoopGuard·Loopers: 무료(오픈소스) |
| 주목할 가치 | 에이전트 무한 루프는 기존 프레임워크에서 주로 개발자가 max_iterations 파라미터로만 제어했다. 이 도구들은 콘텐츠 기반 반복 탐지(동일 페이로드 해싱, 툴 콜 시퀀스 분석)를 추가해 실행 중 런타임 안전망을 제공한다 |

**유사 카테고리 비교**

| | NakshGuard | LoopGuard | Loopers |
|---|---|---|---|
| 동작 방식 | 역방향 프록시 (요청 경로) | 데몬 모니터링 (외부 관찰) | Go 미들웨어 (500+ 모델) |
| 지원 에이전트 | 모든 HTTP 기반 에이전트 | Claude Code, Codex, Gemini CLI | MCP 툴 콜 기반 |
| 탐지 방식 | 페이로드 검사·반복 패턴 | 세션 실시간 모니터링 | 결정적 툴 콜 횟수 카운터 |
| 설치 지연 | +20~50ms (프록시 오버헤드) | 없음 (외부 데몬) | 미확인 |

**5분 검증 액션** [NakshGuard 기술 리뷰 글](https://aiindigo.com/blog/nakshguard-deep-dive-technical-review)에서 "반복 탐지 알고리즘" 섹션을 읽고, 현재 운용 중인 에이전트의 최대 허용 반복 횟수 설정과 비교해본다.

해당 카테고리는 일부 플랫폼의 third-party 접근 정책에 따라 사용에 제약이 있을 수 있어 별도로 분류합니다. 도구 사용 전 자신의 상황·계약·정책에 맞는지 확인이 필요합니다.

- [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) — AI 에이전트가 공식 API 없이 Twitter, Reddit, YouTube, Bilibili, XiaoHongShu 등 플랫폼을 스크래핑·검색할 수 있게 해주는 오픈소스 Python CLI. 인증 방식: 각 플랫폼 로그인 쿠키·세션 기반(공식 API key 불필요). 프로젝트 자체 README에서 Twitter·Reddit 등의 로그인이 필요한 플랫폼에는 계정 차단 위험이 있어 별도 계정 사용을 권장한다고 명시하고 있다. 각 플랫폼의 robots.txt 및 서비스 이용 약관은 자동화된 스크래핑을 일반적으로 제한하므로, 사용 전 해당 플랫폼의 정책 확인이 필요하다.
