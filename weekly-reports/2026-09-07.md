### 1. [Claude Agent Skills API — 정식 출시(GA)](https://www.aiagentslibrary.com/blog/claude-skills-api/)

**무엇** Anthropic의 Claude API에서 Agent Skills 및 Skills API(`/v1/skills`)가 베타를 종료하고 정식 출시됐다. 팀이 작성한 커스텀 스킬을 Claude 코드 실행 샌드박스에 업로드·버전 관리하여 별도 서버 없이 에이전트에 배포할 수 있다. Messages API의 `container` 파라미터로 스킬을 로드하는 방식도 베타 헤더 없이 동작한다.

**쉬운 비유** 자주 쓰는 요리 레시피를 주방 공용 카드함에 등록해 두면, 누가 만들어도 같은 맛이 나듯이—팀이 작성한 에이전트 절차를 한 번 등록해 두면 어느 에이전트 호출에서도 동일하게 꺼내 쓸 수 있다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Anthropic API key (BYOK) |
| 비용 | 무료(오픈 엔드포인트, Claude API 호출 비용 별도) |
| 주목할 가치 | 기존 베타 헤더(`skills-2025-10-02`) 제거로 프로덕션 연동 간소화. 스킬을 Anthropic 샌드박스에서 호스팅하므로 별도 실행 환경 불필요. 버전 관리 API 제공으로 팀 단위 재사용 가능 |

**유사 카테고리 비교**

| | Claude Skills API | 시스템 프롬프트 직접 삽입 | 외부 MCP/도구 서버 |
|---|---|---|---|
| 재사용성 | API로 버전 관리 및 팀 공유 | 매 호출마다 직접 삽입 | 서버 코드 유지보수 필요 |
| 실행 환경 | Anthropic 샌드박스 | 없음 | 자체 인프라 |
| 배포 복잡도 | 없음 | 없음 | 중간~높음 |
| 상태 유지 | Anthropic 관리 | 클라이언트 책임 | 서버 책임 |

**5분 검증 액션** Anthropic Developer Platform의 릴리스 노트에서 "Agent Skills and the Skills API out of beta" 항목을 확인한 뒤, `/v1/skills` 엔드포인트 레퍼런스 페이지에서 업로드 및 버전 관리 방식을 훑어본다.

### 2. [Google Antigravity 2.0](https://antigravity.google/)

**무엇** Google이 Antigravity를 IDE 확장 수준에서 독립형 에이전트 조율 앱으로 발전시킨 Antigravity 2.0을 공개했다. 에디터, 터미널, 브라우저, 로컬 파일을 가로질러 최대 5개의 에이전트를 각자 다른 작업·워크스페이스에 병렬 배치하고 Manager 뷰 한 화면에서 조율할 수 있다. 에이전트 실행 결과를 작업 목록·구현 계획·브라우저 녹화 등 "Artifact"로 자동 저장해 검증할 수 있다.

**쉬운 비유** 주방장이 다섯 명의 요리사에게 각자 다른 요리를 동시에 맡기고, 한 자리에서 진행 상황을 보면서 순서를 조정하는 것과 같다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | Google 계정 (Gemini API 기반). 자체 API key 연동 가능 여부: 미확인 |
| 비용 | Antigravity IDE: 미공개. Gemini API 사용 비용 별도 |
| 주목할 가치 | 에디터 독립형 앱으로 분리된 점이 이전 버전과의 핵심 차이. Cmd+E(macOS) / Ctrl+E(Windows·Linux)로 Editor ↔ Manager 전환. Artifact 기능으로 에이전트 출력 검증 가능 |

**유사 카테고리 비교**

| | Google Antigravity 2.0 | Claude Code | Cursor |
|---|---|---|---|
| 병렬 에이전트 수 | 최대 5개 (Manager 뷰) | 1개 (세션 단위) | 1개 |
| 독립형 앱 여부 | 있음 | CLI | IDE 내장 |
| 브라우저 에이전트 조율 | 지원 | 미지원 | 미지원 |
| 기반 모델 | Gemini (Google) | Claude (Anthropic) | 선택 가능 |
| Artifact(검증 산출물) | 자동 생성 | 미지원 | 미지원 |

**5분 검증 액션** [Google Antigravity 소개 블로그](https://antigravity.google/blog/introducing-google-antigravity)에서 Manager 뷰 스크린샷과 Artifact 섹션을 확인한다. [Google Codelabs 시작 가이드](https://codelabs.developers.google.com/getting-started-google-antigravity)에서 설치 흐름(약 10분 분량)을 훑어본다.
