## 👀 지금 살펴볼 가치

### 1. [Keenable](https://keenable.ai/)

**무엇** Yandex Search 전 CEO와 Amazon AGI 출신이 설립한 스타트업이 공개한 에이전트 전용 웹 검색 인프라. 1,000억 건 문서 인덱스와 MCP 서버를 제공하며, 프로토타이핑 단계에서는 API 키 없이 시간당 1,000회 요청이 가능하다. 에이전트가 수천 개의 라이브 소스에서 동시에 데이터를 가져오는 고유 쿼리 언어(WQL)와 특정 과거 시점의 웹 상태를 조회하는 point-in-time 검색을 지원한다. 8월 25일 Accel 주도 $2,600만 시드 라운드와 함께 스텔스 공개.

**쉬운 비유** 도서관 사서가 '오늘 자 신문'뿐 아니라 '작년 특정 날짜의 신문'까지 즉시 꺼내줄 수 있는 배달 시스템을, 사람이 아닌 자동 업무 처리 로봇 전용으로 만들어 둔 것.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 키리스(무료 티어, 시간당 1,000 요청) / API 키(유료 고용량 티어) |
| 비용 | 무료 티어 제공 / 고용량 플랜 구독제 (금액 미공개) |
| 주목할 가치 | Bing/Google Search API를 대체하는 에이전트 최적화 검색 인프라. MCP 서버를 기본 제공해 별도 연동 없이 에이전트 파이프라인에 즉시 연결 가능. 과거 시점 검색(point-in-time)은 유사 도구에서 보기 드문 기능으로, 시계열 정보 비교가 필요한 에이전트 사용 사례에 차별점이 된다. |

**유사 카테고리 비교**

| | Keenable | Bing Search API | Tavily |
|---|---|---|---|
| MCP 서버 기본 제공 | ✓ | ✗ | 별도 커뮤니티 서버 |
| 키리스 무료 티어 | 시간당 1,000 req | 제한적 | 월 1,000 req |
| 과거 시점 검색 | ✓ | ✗ | ✗ |
| 인덱스 규모 | 1,000억 문서 공개 | 미공개 | 미공개 |

**5분 검증 액션** [keenable.ai](https://keenable.ai/) 접속 → API 키 없이 MCP 서버 엔드포인트 문서 확인 → 로컬 에이전트에 MCP 서버 한 줄 연결 테스트

## 📝 인지만 해두면 OK

- [Microsoft Agent Framework .NET 1.19.0](https://github.com/microsoft/agent-framework/releases) — 에이전트 훅 인터셉션(실험적), MCP 2026-07-28 태스크 확장 지원, Azure Blob Storage 세션 영속화 추가 (~8월 28일). 기존 프레임워크의 마이너 업데이트이므로 신규 도입 검토보다는 기존 사용자 업그레이드 참고 항목.

- [AccuKnox AgentZ](https://www.accuknox.com/) — 모델 무관 에이전트 플랫폼, 8월 28일 공식 출시. 보안 중심 기업 고객 대상으로 보이며, 일반 에이전트 개발자 대상 상세 기술 문서가 아직 충분하지 않은 단계.

- [Perplexity + NVIDIA Portable Computer](https://aiagentstore.ai/ai-agent-news/this-week) — 8월 25일 발표. Perplexity 에이전트의 오케스트레이터·플래너·모델을 NVIDIA DGX Spark 하드웨어에서 로컬 구동하는 번들. DGX Spark 보유 환경 한정 가치이므로 메인 목록에 포함하기에는 접근성이 낮음.

- [MCP 로드맵 업데이트](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/) — 8월 22일 발표. 스테이트리스 코어(2026-07-28 스펙)로 전환 이후 5개 우선순위 공개: 에이전트 메시지, HTTP 네이티브 전송, 에이전트 신원 체계, 원시 기능 개선, SDK 정리. MCP 서버·클라이언트를 직접 구현하는 개발자라면 방향성 파악 차원에서 확인 권장.

- [에이전트 자기전파 공격 연구](https://thehackernews.com/2026/07/weekly-recap-rogue-ai-agents-check.html) — Anthropic·EPFL 공동 연구. 시스템 프롬프트 파일을 통해 페이로드가 에이전트 간에 전파되는 기법을 6개 에이전트 협업 시뮬레이션 환경에서 실증. 멀티에이전트 파이프라인 설계 시 입력 신뢰 경계 점검이 필요함을 보여줌.
