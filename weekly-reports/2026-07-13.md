### 1. [OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)

**무엇** AI 에이전트가 Word(.docx), Excel(.xlsx), PowerPoint(.pptx) 파일을 직접 읽고 편집·자동화할 수 있는 단일 바이너리 CLI 도구. Microsoft Office 설치 없이 macOS·Linux·Windows에서 동작하며, 문서를 HTML·PNG로 렌더링해 에이전트가 출력 결과를 확인한 뒤 수정하는 루프를 닫는다.

**쉬운 비유** AI 비서에게 서류 캐비닛 열쇠를 쥐여주는 것. 비서가 파일을 꺼내 읽고, 수정하고, 다시 정리해 넣는 모든 일을 말 한마디로 처리한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (OfficeCLI 자체 계정 불필요; LLM 호출 비용은 사용 중인 에이전트 설정 따름) |
| 비용 | 무료 오픈소스 (MIT); LLM 호출 비용은 별도 |
| 주목할 가치 | 350개 이상 Excel 수식 엔진 내장, HTML·PNG 렌더링으로 에이전트의 "쓴 것 확인" 루프 지원. Claude Code·Cursor·Windsurf·GitHub Copilot 등 기존 코딩 에이전트에 바로 연결 가능. 2026-07-06 최신 릴리스 |

**유사 카테고리 비교**

| | OfficeCLI | python-docx + openpyxl | LibreOffice CLI |
|---|---|---|---|
| 단일 바이너리 | ✅ | ❌ (Python 환경 필요) | ❌ (설치 필요) |
| 에이전트용 렌더링 (HTML/PNG) | ✅ | ❌ | 제한적 |
| Excel 수식 평가 | ✅ (350+ 함수) | 제한적 | ✅ |
| PowerPoint 지원 | ✅ | ❌ | ✅ |
| 설계 대상 | AI 에이전트 | 스크립트 | 일반 변환 |

**5분 검증 액션** GitHub README의 Quick Start 섹션에서 단일 설치 명령 실행 → `.docx` 파일 대상으로 `officecli read` 한 줄 테스트

### 2. [best-of-Agent-Harnesses](https://github.com/RyanAlberts/best-of-Agent-Harnesses)

**무엇** 124종 이상의 AI 에이전트 하네스를 GitHub stars·복잡도·자율성·오류 복구 능력 기준으로 평가·순위화한 큐레이션 목록. 매주 재점수를 산정하며 공식 MCP 서버(`uvx agent-harnesses-mcp`)와 `llms.txt`를 함께 제공해, 에이전트 자신이 적합한 하네스를 조회할 수 있다. 2026-07-12 기준 데이터 반영.

**쉬운 비유** "어떤 작업에 어떤 공구가 맞는지"를 정리한 공구 카탈로그. 직접 비교 대신 카탈로그에 "나는 이런 일을 한다"고 물어보면 맞는 공구를 바로 추천받는 방식.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (조회 전용; MCP 서버 설치만 필요) |
| 비용 | 무료 오픈소스 |
| 주목할 가치 | 에이전트가 MCP를 통해 `recommend`, `pick_harness`, `search_harnesses` 명령으로 하네스를 스스로 선택하는 메타 패턴. 진입 단계·자율성 수준·오류 복구 여부 등 실무 기준으로 분류. 105개 이상이 명확한 오픈소스 라이선스 |

**5분 검증 액션** `uvx agent-harnesses-mcp` 설치 → 현재 진행 중인 프로젝트 유형 입력해 `search_harnesses` 명령으로 추천 결과 확인

### 3. [mattpocock/skills](https://github.com/mattpocock/skills)

**무엇** 실무 소프트웨어 개발용 AI 에이전트 스킬 컬렉션. `.claude` 디렉터리 기반으로 설계됐으며 `to-spec`(대화→사양서), `to-tickets`(계획→작업 티켓), `implement`(TDD 방식 구현), `diagnosing-bugs`(버그 진단 루프) 스킬이 포함된다. 스킬 단위가 작고 교체 가능해 부분 적용이 쉽다. 2026-07-12 기준 이슈 활동 확인됨.

**쉬운 비유** 숙련된 장인이 자기 작업 루틴을 레시피로 공개한 것. 재료 선정부터 설계·가공·검수까지 단계별 절차가 적혀 있어 전체 흐름을 따라가거나 필요한 단계만 골라 쓸 수 있다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 없음 (스킬 파일 기반; LLM 연동은 사용 중인 에이전트 설정 따름) |
| 비용 | 무료 오픈소스 |
| 주목할 가치 | 대화→사양→티켓→구현→검토로 이어지는 완전한 개발 루프를 스킬 단위로 제공. 모델 종속 없이 설계됐고 각 스킬을 독립적으로 교체 가능 |

**유사 카테고리 비교**

| | mattpocock/skills | Claude Code 기본 스킬 | OpenHarness 스킬 |
|---|---|---|---|
| 개발 루프 스킬 | ✅ 완전한 루프 | 부분적 | 도구 중심 |
| 모델 종속 여부 | 모델 무관 | Claude 최적화 | 다중 LLM |
| 커스터마이징 | ✅ (작은 단위) | 제한적 | ✅ |
| 주 대상 | 개발 워크플로 | 범용 | 개인 에이전트 |

**5분 검증 액션** `skills/engineering` 폴더 구조 확인 → `to-spec` 또는 `diagnosing-bugs` 스킬 파일 하나를 읽고 기존 `.claude` 설정에 통합 검토

### 4. [openai/codex-plugin-cc](https://github.com/openai/codex-plugin-cc)

**무엇** Claude Code 세션 안에서 OpenAI Codex를 호출해 코드 리뷰와 작업 위임을 할 수 있는 OpenAI 공식 플러그인. `/codex:review`(코드 리뷰), `/codex:transfer`(세션 이관), `/codex:status`, `/codex:result` 명령을 제공한다. 2026-03-31 최초 공개 후 2026-07-06 주간 트렌딩 급등(5,900+ stars).

**쉬운 비유** 서로 다른 회사 소속 검토 전문가를 같은 작업실로 부를 수 있는 방문증. 자리를 벗어나지 않고도 외부 전문가의 의견을 받거나 작업을 넘길 수 있다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | OpenAI 계정(Codex 이용 자격) + Claude Code 설치 환경 |
| 비용 | 플러그인 자체 무료 오픈소스; Codex 이용 비용은 OpenAI 요금제 따름 |
| 주목할 가치 | 서로 다른 LLM 공급사 도구를 단일 세션에서 연동하는 크로스 모델 협업의 공식 사례. 세션 이관(`/codex:transfer`)으로 Claude Code에서 시작한 컨텍스트를 Codex에서 이어서 작업 가능 |

**5분 검증 액션** README의 Installation 섹션 → `codex:setup` 명령으로 환경 준비 → `/codex:review` 로 현재 작업 중인 파일 대상 테스트 리뷰

- [OpenAI 커뮤니티 소개 글](https://community.openai.com/t/introducing-codex-plugin-for-claude-code/1378186)
