### 1. [Bernstein](https://github.com/sipyourdrink-ltd/bernstein)

**무엇** Claude Code·Codex·Gemini CLI·Aider 등 43개 이상의 CLI 코딩 에이전트를 단일 오케스트레이터 아래서 결정론적으로 병렬 실행하는 오픈소스 멀티에이전트 하네스. 스케줄러 자체는 순수 Python으로 작성되어 LLM 토큰을 소비하지 않는다. HMAC 체인 감사 로그·Ed25519 서명·린트/타입/테스트 게이트가 모든 병합 단계에 내장되어 있으며 Jira·Linear·Plane 등 10종 이슈트래커 어댑터, MCP 클라이언트/서버, Playwright UI 샌드박스, SBOM 지원도 포함한다.

**쉬운 비유** 여러 명의 전문 직원을 각자 별도의 작업실에 동시에 투입한 뒤, 각 방의 결과물에 회사 인감을 찍어 하나의 결재 서류로 합치는 공장 라인과 같다. 라인 관리자(스케줄러)는 즉흥 판단 없이 미리 정해진 절차만 따른다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 각 에이전트가 자체 API 키 사용 (BYOK) — Claude Code는 Anthropic API key, Codex는 OpenAI API key 등 에이전트별 상이 |
| 비용 | 무료(오픈소스, MIT) / 각 에이전트 LLM 호출 비용 별도 |
| 주목할 가치 | 멀티에이전트 오케스트레이터 중 스케줄러 레이어에 LLM을 일절 사용하지 않는 결정론적 설계가 차별점. 동일 입력·동일 결과 재현이 가능하며 감사 로그가 HMAC으로 체인되어 위변조 추적이 가능하다. |

**유사 카테고리 비교**

| | Bernstein | CrewAI | LangGraph |
|---|---|---|---|
| 스케줄러 방식 | 순수 Python (결정론적, LLM 불사용) | LLM 기반 역할 조율 | 그래프 기반 (코드 정의) |
| 지원 에이전트 | 43개 CLI 코딩 에이전트 범용 래퍼 | 커스텀 Crew 에이전트 | 커스텀 그래프 노드 |
| 감사 로그 | HMAC 체인 + Ed25519 서명 | 없음 | 없음 |
| 엔터프라이즈 컴플라이언스 | SBOM, OSSF Scorecard, 이슈트래커 10종 | 없음 | 없음 |

**5분 검증 액션** GitHub README의 "Architecture" 섹션에서 스케줄러 다이어그램 확인 → `pip install bernstein` 후 `bernstein demo` 명령으로 샘플 태스크 실행

### 2. [Microsoft RAMPART & Clarity](https://www.microsoft.com/en-us/security/blog/2026/05/20/introducing-rampart-and-clarity-open-source-tools-to-bring-safety-into-agent-development-workflow/)

**무엇** RAMPART는 AI 에이전트 시스템을 대상으로 프롬프트 인젝션·도구 남용 등의 적대적 시나리오를 반복 실행 가능한 테스트로 정의하고 CI/CD 파이프라인에 내장하는 pytest 기반 오픈소스 프레임워크다. Microsoft의 오픈소스 레드팀 자동화 툴킷인 PyRIT 위에 구축됐다. Clarity는 구현 전 설계 가정을 검증하는 구조화 도구로, 여러 'AI 사고자'가 보안·인적 요인·운영·적대적 시나리오 관점에서 시스템을 분석해 피드백한다.

**쉬운 비유** RAMPART는 건물을 짓기 전에 가상의 침입자를 고용해 취약 지점을 찾는 모의 침입 훈련이고, Clarity는 설계도를 여러 전문가가 함께 놓고 "이 구조 정말 괜찮냐"고 체계적으로 따져보는 검토 회의다. 두 도구 모두 코드 작성 단계가 아닌 설계·빌드 루프 안에서 동작한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 오픈소스 (Microsoft GitHub 공개). 테스트 대상 에이전트 LLM은 BYOK |
| 비용 | 무료(오픈소스) |
| 주목할 가치 | 에이전트 안전 테스트를 '출시 후 별도 보안 검토' 단계가 아닌 CI/CD 루프 안으로 끌어들인 점이 특징. PyRIT 기반이라 기존 Microsoft 레드팀 파이프라인과 통합이 비교적 용이하다. |

### 3. [NVIDIA Verified Agent Skills & SkillSpector](https://developer.nvidia.com/blog/nvidia-verified-agent-skills-provide-capability-governance-for-ai-agents/)

**무엇** AI 에이전트 스킬 패키지에 소프트웨어 공급망 보안 관행을 적용한 프레임워크(2026-05-22 출시). 소스 리포 → 리뷰 → 보안 스캔 → 평가 → 스킬 카드 생성 → 암호화 서명 → 카탈로그 등 8단계 파이프라인을 거친 162개의 서명된 스킬이 16개 제품군에 걸쳐 공개 카탈로그로 제공된다. SkillSpector는 취약한 의존성·위험 코드 패턴·자격증명 접근·데이터 유출 경로 등 64개 패턴을 검사하는 오픈소스 스캐너다.

**쉬운 비유** 식품 공장에서 외부 재료가 들어올 때 원산지 확인·성분 분석·유통기한 표기까지 마친 뒤 인증 마크를 붙이는 검수 절차와 같다. 여기서 '식재료'가 에이전트 스킬 패키지다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 공개 카탈로그 (별도 인증 불필요) / SkillSpector는 오픈소스 (MIT 예정) |
| 비용 | 무료(오픈소스) |
| 주목할 가치 | 에이전트 스킬 패키지의 공급망 보안을 표준화하려는 초기 시도로, 기계 가독형 스킬 카드와 암호화 서명 체계가 포함된다. 프로덕션 에이전트 시스템에서 외부 스킬 패키지를 도입할 때 검증 기준점으로 활용 가능하다. |

**5분 검증 액션** [NVIDIA Technical Blog](https://developer.nvidia.com/blog/nvidia-verified-agent-skills-provide-capability-governance-for-ai-agents/)에서 8단계 파이프라인 다이어그램 확인 → GitHub에서 SkillSpector 레포를 열어 64개 취약점 패턴 목록 열람
