### 1. [LlamaIndex Workflows 2.26.0 + DBOS 내구성 실행 통합](https://docs.dbos.dev/integrations/llamaindex)

**무엇** `llama-agents-dbos` 패키지를 통해 LlamaIndex Workflows의 각 스텝 전환 상태를 DB에 영속 저장한다. 에이전트가 실행 중 종료되더라도 마지막 완료 틱에서 재개되며, 수동 체크포인트 코드 없이 기존 워크플로우 코드에서 런타임만 교체하면 적용된다.

**쉬운 비유** 긴 게임 진행 중 전원이 꺼져도, 자동 저장 덕분에 마지막 저장 지점부터 다시 이어 할 수 있는 것과 같다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 무료(오픈소스) — llama-agents-dbos 패키지; DBOS 서버 또는 DBOS Cloud 별도 필요 |
| 비용 | 무료(오픈소스, LLM 호출 비용 별도); DBOS Cloud는 별도 요금 구조 (공개 가격 미확인) |
| 주목할 가치 | `WorkflowRuntime` → `DBOSRuntime` 한 줄 교체로 내구성 실행 적용. 에이전트 장애 복구가 프레임워크 레벨에서 해결되는 보기 드문 통합으로, 프로덕션 에이전트 루프의 안정성 요구를 직접 다룬다. |

**유사 카테고리 비교**

| | LlamaIndex + DBOS | Temporal | Prefect |
|---|---|---|---|
| 통합 방식 | LlamaIndex Workflows 런타임만 교체 | 별도 워크플로 DSL 재작성 | DAG / Flow 재작성 |
| 에이전트 친화도 | LlamaIndex 에이전트 네이티브 | 범용 워크플로 오케스트레이션 | 범용 데이터 파이프라인 |
| 호스팅 옵션 | 셀프호스트 DBOS / DBOS Cloud | Temporal Cloud / 셀프호스트 | Prefect Cloud / 셀프호스트 |
| 기존 코드 변경량 | 런타임 교체 1줄 | 상당 수준 재작성 | 상당 수준 재작성 |

**5분 검증 액션** [DBOS LlamaIndex 통합 공식 문서](https://docs.dbos.dev/integrations/llamaindex)의 quickstart 예제에서 `DBOSRuntime`으로 교체하는 부분만 읽고, 기존 워크플로우 코드에 적용 가능한지 확인한다.

### 2. [ServiceNow ToolSmith](https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-introduces-the-third-generation-of-its-employee-centric-AI-harness-so-the-workforce-can-build-and-use-the-AI-their-jobs-demand/default.aspx)

**무엇** ServiceNow EmployeeWorks용 에이전트 도구를 자연어 설명으로 자동 생성하는 개발 환경(Oct 15, controlled availability). 75,000개 이상의 API를 사전 학습해 계획·구현·디버그·테스트를 동일한 대화형 인터페이스 안에서 처리하며, 토큰 효율성과 신뢰도에 최적화된 도구 코드를 생성한다고 발표했다.

**쉬운 비유** 원하는 제품을 말로 설명하면 부품을 조합해 바로 조립해 주는 공장 로봇에 비유할 수 있다. 도면(코드)을 직접 그리지 않아도 된다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 자체 백엔드 + ServiceNow 구독 (controlled availability — 관리자 정의 가드레일 포함) |
| 비용 | ServiceNow 구독제 (공개 가격 미확인) |
| 주목할 가치 | 에이전트 도구를 자연어로 명세하고 코드 생성·테스트·배포를 단일 인터페이스로 통합한 접근 방식은 에이전트 하네스 엔지니어링 자동화의 실험적 선례로 주목할 만하다. 현재 ServiceNow 플랫폼 종속이지만, 유사 개념이 독립형 도구로 확장될 가능성이 있다. |

**유사 카테고리 비교**

| | ServiceNow ToolSmith | Cursor Agent mode | LangChain LCEL |
|---|---|---|---|
| 도구 생성 타겟 | ServiceNow EmployeeWorks 에이전트 | 범용 코드베이스 | LangChain 에이전트 도구 |
| API 사전 학습 | 75,000+ 내부 API | 미확인 | 미확인 |
| 배포 통합 | ServiceNow 플랫폼 네이티브 | 수동 배포 | 별도 런타임 배포 필요 |
| 접근 방식 | 자연어 → 도구 코드 자동 생성 | 자연어 → 범용 코드 | 수동 도구 정의 |

**5분 검증 액션** [InfoWorld 기사](https://www.infoworld.com/article/4235886/servicenow-makes-it-easier-to-build-ai-agents-gives-them-verifiable-identities-2.html)에서 ToolSmith의 데모 시나리오와 controlled availability 진입 조건을 확인한다.
