# Weekly AI Agent Tech Scan — 2026-06-08

## 🎯 TL;DR

- **Microsoft가 Build 2026(6/2~6/3)에서 Agent Framework의 CodeAct를 공개**했다. 모델이 도구를 하나씩 고르며 왕복하는 대신 `call_tool(...)`을 호출하는 짧은 Python 프로그램 한 장을 작성해 한 번에 실행한다. 호출마다 일회용 Hyperlight 마이크로 VM에서 격리 실행돼 도구 호출 단위의 강한 격리를 거의 공짜로 얻는다.
- **Anthropic Agent SDK 과금이 6/15부터 분리**된다. Agent SDK·`claude -p`·Claude Code GitHub Actions·서드파티 앱은 구독 한도가 아니라 별도 월 크레딧($20 Pro / $100 Max 5x / $200 Max 20x, API 요율, 롤오버 없음)에서 차감된다. 크레딧 소진 시 overflow를 켜두지 않으면 자동 요청이 멈춘다. 자동화 에이전트를 운영 중이면 6/15 전 확인이 필요하다.
- **Claude Code 6월 업데이트**로 최대 3개까지 순서대로 시도하는 `fallbackModel`, deny 규칙의 glob 패턴 지원("*"로 전체 도구 차단), 세션 간 메시지 보안 강화가 들어갔다. Opus 4.8은 Max·Team Premium·Enterprise PAYG·API의 기본 모델이 됐다.
- **MCP 최종 명세가 7/28로 다가온다**. 5/21 RC(무상태 코어·Extensions·Tasks·MCP Apps·인증 강화)가 그대로 확정될 예정이며, Tier 1 SDK는 그 전까지 지원이 목표다. MCP 서버 운영 중이면 breaking change 점검이 필요하다.

## 👀 지금 살펴볼 가치

### 1. [Microsoft Agent Framework — CodeAct (Build 2026)](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-at-build-2026-announce/)

**무엇** Microsoft가 Build 2026(6/2~6/3)에서 오픈소스 Agent Framework(MAF, .NET/Python 동일 API, 4/2 1.0 GA)의 새 실행 방식 **CodeAct**를 발표했다. 기존 에이전트는 "도구 선택 → 대기 → 다음 도구 선택"을 반복하지만, CodeAct는 모델이 여러 도구를 `call_tool(...)`로 호출하는 짧은 Python 프로그램 한 장을 작성해 샌드박스에서 **한 번** 실행하고 통합 결과를 돌려받는다. 이 코드는 `agent-framework-hyperlight`(alpha) 패키지를 통해 **호출마다 새로 뜨는 로컬 격리 Hyperlight 마이크로 VM**에서 실행돼, 단일 도구 호출 단위의 강한 격리를 사실상 비용 없이 얻는다. 같은 발표에서 셸·파일시스템 접근·HITL 승인·장기 세션 컨텍스트 관리를 담당하는 **Agent Harness** 레이어와, 컨테이너 에이전트를 Foundry에 배포하는 **Hosted Agents**(scale-to-zero, 파일시스템·세션 상태 유지)도 함께 공개됐다.

**쉬운 비유** 종업원에게 "재료 가져와 → (대기) → 썰어 → (대기) → 구워"를 한 단계씩 시키는 대신, 레시피 한 장을 통째로 건네 주방에서 한 번에 처리하게 하는 것과 같다. 게다가 그 주방은 요리할 때마다 새로 차려지는 일회용 격리 주방(마이크로 VM)이라, 사고가 나도 본채로 번지지 않는다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 오픈소스 SDK (Microsoft GitHub). 모델은 BYOK (Azure OpenAI·OpenAI 등) |
| 비용 | 무료(오픈소스, MIT). `agent-framework-hyperlight`는 alpha 단계 / 모델 호출 비용 별도 |
| 주목할 가치 | 도구 선택 루프를 "코드 1회 실행"으로 접어(collapse) LLM 왕복 횟수·지연을 줄이는 CodeAct 패턴이 핵심. 호출당 Hyperlight 마이크로 VM 격리로 코드 실행 보안을 세분화한 점이 차별점. MAF 1.0(4/2 GA) 위의 확장이라 .NET·Python 양쪽에서 동일하게 쓸 수 있다. |

**유사 카테고리 비교**

| | CodeAct (MAF) | 전통 ReAct tool-calling | 일반 코드 인터프리터 에이전트 |
|---|---|---|---|
| 도구 호출 방식 | 코드 1장에 다중 `call_tool` → 1회 실행 | 도구 1개씩 선택·대기 반복 | 모델이 자유 코드 작성·실행 |
| LLM 왕복 | 적음 (배치 실행) | 많음 (도구마다 왕복) | 중간 |
| 격리 | 호출당 Hyperlight 마이크로 VM | 도구 구현에 의존 | 단일 샌드박스 공유가 일반적 |
