### 2. [sickn33/agentic-awesome-skills — 2,000+ SKILL.md 플레이북 카탈로그](https://sickn33.github.io/agentic-awesome-skills)

**무엇** `skills/<이름>/SKILL.md` 형태로 구성된 2,100개 이상의 커뮤니티 제작 플레이북 카탈로그. 로컬 MCP 서버, 로컬 CLI, 브라우저 Workbench를 함께 제공하며 `npx skills add sickn33/agentic-awesome-skills --skill <이름>` 한 줄로 설치한다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 무료(오픈소스) — 코드 MIT, 스킬 콘텐츠 CC BY 4.0 |
| 비용 | 무료 (LLM 호출 비용 별도) |
| 주목할 가치 | Claude Code, Codex CLI, Cursor 등 여러 하네스에서 단일 카탈로그를 공유한다는 점이 주요 에이전트 스킬 저장소 중에서 차별화 요소다. `plugins/` 폴더에는 4,500개 이상의 추가 플레이북이 있다. |

### 3. [wshobson/agents — 크로스 하네스 플러그인 마켓플레이스](https://github.com/wshobson/agents)

**무엇** 단일 Markdown 소스에서 Claude Code, Codex CLI, Cursor, OpenCode, Gemini CLI를 동시 지원하는 플러그인 마켓플레이스. 190개 이상의 전문 에이전트·플러그인·스킬과 함께 정적 분석·LLM 판정·Monte Carlo 테스트를 묶은 `plugin-eval` 품질 평가 프레임워크를 포함한다.

**쉬운 비유** 여러 회사의 스마트폰에서 동시에 다운받을 수 있는 앱 스토어와 같다. 앱(플러그인)을 한 번 만들어 올리면 어느 기기(하네스)에서든 내려받아 쓴다.

| 라벨 | 값 |
|---|---|
| 인증 방식 | 무료(오픈소스) |
| 비용 | 무료 (LLM 호출 비용 별도) |
| 주목할 가치 | 플러그인 하나를 여러 에이전트 하네스에서 재사용할 수 있는 구조와, `uv run plugin-eval score`로 플러그인 품질을 정량 측정하는 자동화 평가 프레임워크를 함께 제공하는 점이 이 카테고리에서 드문 조합이다. |

**유사 카테고리 비교**

| | wshobson/agents | sickn33/agentic-awesome-skills | Claude.ai 내장 플러그인 |
|---|---|---|---|
| 지원 하네스 | Claude Code, Codex CLI, Cursor, OpenCode, Gemini CLI | Claude Code, Codex CLI, Cursor 등 | Claude 전용 |
| 품질 평가 도구 | plugin-eval (LLM 판정 + Monte Carlo) | 미확인 | 없음 |
| 콘텐츠 | ~190 에이전트, ~155 스킬, ~100 커맨드, ~80 플러그인 | 2,100+ SKILL.md + 4,500+ plugins | 플랫폼 한정 |
| 멀티 하네스 빌드 방식 | 단일 Markdown 소스 → 각 하네스 포맷 자동 생성 | npx 설치 | 해당 없음 |

**5분 검증 액션** [vibeindex.ai 마켓플레이스 페이지](https://vibeindex.ai/marketplaces/wshobson/agents)에서 카테고리별 플러그인 목록을 훑고, GitHub 레포 README의 Claude Code 설치 경로(` /plugin marketplace add wshobson/agents`)를 확인한다.
